## Partial slice evidence (not sign-off)

PR [#318 at `b541262`](https://github.com/trickle-labs/rockstream/commit/b5412623b77fab91ff5c4ad5e61b2f4a491e3469) ran `rtk cargo test --release -p rockstream-cli --test oidc_release_process_tests -- --test-threads=1` with 4 passing tests. The release-process tests cover nine required negative cases across enabled SCRAM, OIDC, mTLS, and internal-node configurations: invalid password, invalid SCRAM proof, expired OIDC token, wrong issuer, wrong audience, insufficient role, expired certificate, wrong CA, and wrong node identity. They do not cover rotation during operation.

Rotation during operation remains blocked evidence: the CLI has no supported release-process TLS-reload route, while the documented `ControlServiceHandle::reload_tls` tests run in-process. This slice evidence does not qualify an integrated v0.73 candidate; keep all exit criteria unchecked.
