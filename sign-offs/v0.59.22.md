## Notable scope decisions

- Formal environment classification tiers (`Supported`, `Compatible, unverified`, `Unsupported`) codified in `contracts/platform-matrix.toml` and evaluated by `PlatformClassifier` in `rockstream-types`.
- Startup pre-flight validation automatically logs platform details, emits informational warnings for `Compatible, unverified` environments (e.g. S3 clones, non-LTS Linux), and rejects `Unsupported` platforms (32-bit architectures, glibc < 2.31, NFS/SMB mounts) with fatal diagnostic `RS-3024`.
- Standardized OCI container packaging running as non-root user `rockstream` (UID 10001, GID 10001), supporting read-only root filesystems (`--read-only --tmpfs /tmp`), and exposing standard ports (`5432`, `9090`, `9100`, `9200`).
- Reference Docker Compose profiles (`standalone`, `distributed`, `cdc`) and production systemd unit files with security sandboxing (`ProtectSystem=strict`, `ProtectHome=yes`, `NoNewPrivileges=yes`, `PrivateTmp=yes`, `MemoryDenyWriteExecute=yes`, `LimitNOFILE=65536`).
- Production Kubernetes manifests and minimal Helm chart enforcing Pod Security Standards `restricted` profile and configuring `/live` and `/ready` HTTP lifecycle probes.
- Comprehensive `rockstream doctor` platform, libc, container security, storage filesystem, and external backend compatibility checks.
- Documented zero-downtime rolling upgrade sequencing and sizing guidance in `docs/rolling-upgrades.md`, `docs/deployment-profiles.md`, and `docs/platforms.md`.
