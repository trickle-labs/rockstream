## Notes

Full evidence (commands, outputs, and the exact proof mapping) is recorded in
`.claude/v0.51.2-evidence.md`. v0.51.2 routes ad hoc `SELECT` statements
(`WHERE`, two-table `JOIN`, `GROUP BY`/aggregates, scalar/`IN` subqueries,
`WITH` CTEs) against already-materialized tables/views through the same
DataFusion engine already used at view-materialization time, replaces the
one-line pushdown/index-annotation stub for plain `EXPLAIN <query>` with a
real DataFusion-generated plan tree (leaving `EXPLAIN INCREMENTAL` from v0.45
byte-for-byte unchanged), and wires the already-tracked
`CatalogIndexState::Building`/`Ready` secondary-index metadata (v0.32) into
this new query-time execution path as a real point/range-lookup accelerator,
so standard `CREATE INDEX` DDL stops being metadata-only.

All 15 Proof-Mapping rows from `.claude/v0.51.2-plan.md` §7 are satisfied
with passing, live-pgwire tests (12 in the primary 3-suite run plus 2 real
MinIO durability tests). No oracle/property test beyond the hand-computed
`ad_hoc_*_matches_oracle` tests is owed — per plan §4, no new IVM/DBSP
operator is introduced (Slices 1-4 reuse `view_materializer.rs`'s existing
read-only `MemTable` pattern; Slice 5's backfill is a one-time scan). No
`SimRuntime`/`buggify!()` test is owed per plan §6 — all work is
single-shard, gateway-local (hardcoded shard `0`), with no cross-shard/
cross-node coordination path introduced. The full `rockstream-gateway` test
suite (272 passed, 1 ignored, 33 suites) is green with zero regressions.
Nothing deferred.
