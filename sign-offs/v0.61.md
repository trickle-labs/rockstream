## Exit Criteria Verification

All exit criteria from [v0.61 implementation plan](../docs/implementation-plans/v0.61.md) have been verified:

- [x] V061-01: Project generation emits the complete six-file contract (`rockstream.toml`, `project.toml`, `schema.sql`, `data/seed.csv`, `queries/verify.sql`, `README.md`) in `crates/rockstream-cli/src/init.rs`; validated by `init_tests::test_project_new_six_file_contract`, `init_tests::test_init_rejects_occupied_destination_without_force`, and `init_tests::test_project_manifest_validation`.
- [x] V061-02: Release binary execution of `rockstream project new`, `start`, `project apply`, `project verify`, and DML `query` operates without direct Rust APIs or external `psql` in `crates/rockstream-cli/src/project.rs` and `crates/rockstream-cli/src/client.rs`; proven by `golden_path_process_tests::full_golden_path_workflow_end_to_end` and `documentation_checks::generated_readme_commands_are_executable`.
- [x] V061-03: `CREATE TABLE`, `CREATE MATERIALIZED VIEW`, CSV seed ingestion, `INSERT`, `UPDATE`, and `DELETE` state tracking validated over pgwire with bit-identical batch recalculation across 40 mutations in `golden_path_process_tests::full_golden_path_workflow_end_to_end` and `golden_path_oracle_tests::sales_view_incremental_equals_batch`.
- [x] V061-04: Embedded pgwire client in `crates/rockstream-cli/src/client.rs` and REPL shell in `crates/rockstream-cli/src/shell.rs` execute simple, prepared, and file SQL with `--timing` across `table`, `json`, and `csv` encodings with explicit `RS-XXXX` error extraction; proven by `client_corpus_tests::simple_and_prepared_queries_across_all_formats`, `client_corpus_tests::sql_file_execution_with_timing`, and `shell_tests::shell_multiline_statement_buffering_and_execution`.
- [x] V061-05: Declarative `project apply` in `crates/rockstream-cli/src/project.rs` halts on first SQL/seed failure, updates `_rockstream_project_metadata` only for completed steps, and provides idempotent repeat apply without duplicating seed rows; proven by `project_apply_tests::clean_apply_succeeds`, `project_apply_tests::repeat_apply_does_not_duplicate_seed_data`, and `project_apply_tests::mid_apply_failure_stops_and_records_partial`.
- [x] V061-06: Structured multiset comparison in `crates/rockstream-cli/src/project.rs` rejects value mismatches, extra rows, missing rows, missing views (`RS-2005`), and unreachable nodes (`RS-0004`) with detailed diff diagnostics; proven by `project_verify_tests::verify_succeeds_on_exact_multiset_match`, `project_verify_tests::verify_fails_with_explicit_diff_on_mismatch`, and `project_verify_tests::verify_fails_nonzero_on_unreachable_node`.
- [x] V061-07: Template selection restricts to `local` with non-local choices directing to `examples/experimental/`; strict bounds enforced on SQL files (10 MB), seed batches (1,000 rows / 2 MB), shell buffers (64 KB), query results (10,000 rows), and connection timeouts; proven by `init_tests::test_template_selection_rejects_non_local`, `bounding_tests::client_and_file_buffers_strictly_enforce_limits`, and `project_coordination_tests::sim_runtime_client_retry_and_timeout_under_loss`.
