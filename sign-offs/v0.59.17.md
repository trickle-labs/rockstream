## Notable scope decisions

- `language.historical-streaming-reads` and the 3 connector/sink capabilities have no real-Postgres differential equivalent (`SUBSCRIBE`, CDC/Kafka wire protocols). Their `_matches_*` tests compare RockStream's real dispatch path against a genuinely independent second observer (a second `InProcessDriver` invocation, or a raw `tokio-postgres`/`rdkafka` client reading the same source/topic directly) rather than against Postgres — each test's doc comment states the substitution.
- `language.transaction-semantics`'s differential test omits `BEGIN`/`COMMIT` on the RockStream side (a bare DataFusion `SessionContext` rejects them); only the shared DML/SELECT statements are compared.
- `min_proof_level` drops `L2` (pgwire-public) for the 3 connector/sink capabilities — their reachability is "Connector runtime", not pgwire, per Matrix A/B of `.claude/v0.59.17-plan.md`.
- `rockstream-oracle` gained a new **dev**-only dependency on `rockstream-connectors` to drive the real CDC/Kafka connector code directly in differential tests; confirmed no reverse (non-dev) dependency exists, so no cycle.
- A pre-existing, out-of-scope gap: `scripts/check-capability-contract.test.sh`'s `roadmap drift` mutation case fails on both this branch and unmodified `main`, because the Python gate never reads `NEW_ROADMAP.md` content — confirmed via `git stash`. Not part of this version's scope (`TST-001`–`TST-006`); not a new deferral.
