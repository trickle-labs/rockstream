## Proof Claims

**Roadmap proof statement:** Failure detection ≤5 s p99, shard reassignment ≤30 s p99, freshness recovery <60 s p99 for 1 TB of state.

### P1 — Failure detection ≤ 5 s p99

- [x] `proof_network_partition_kafka_recovers_within_slo` — Asserts `fd_p99 ≤ 5_000` ms on 24-hour run with network partition faults and Kafka load (seed: 0xA1A1_A1A1_A1A1_A1A1).
- [x] `proof_one_tb_state_recovery_slo` — Asserts `fd_p99 ≤ 5_000` ms with 1 TB nominal state, 32 shards, 24-hour duration, fault_probability=0.005 (seed: 0xA3A3_A3A3_A3A3_A3A3).

**Reproduce:**
```bash
rtk cargo test --test recovery_slo_tests proof_network_partition_kafka_recovers_within_slo
rtk cargo test --test recovery_slo_tests proof_one_tb_state_recovery_slo
```

### P2 — Shard reassignment ≤ 30 s p99

- [x] `proof_one_tb_state_recovery_slo` — Asserts `sa_p99 ≤ 30_000` ms at 1 TB state scale (seed: 0xA3A3_A3A3_A3A3_A3A3).

**Reproduce:**

### P3 — Freshness recovery < 60 s p99 for 1 TB of state

- [x] `proof_network_partition_kafka_recovers_within_slo` — Asserts `fr_p99 ≤ 60_000` ms under network partition and Kafka load (seed: 0xA1A1_A1A1_A1A1_A1A1).
- [x] `proof_brownout_pauses_kafka_source_within_slo` — Asserts `fr_p99 ≤ 60_000` ms under object-store brownout; Kafka catchup ≤ 60 s p99 (seed: 0xA2A2_A2A2_A2A2_A2A2).
- [x] `proof_one_tb_state_recovery_slo` — Asserts `fr_p99 ≤ 60_000` ms explicitly at 1 TB state (seed: 0xA3A3_A3A3_A3A3_A3A3). Recovery timing model: WAL tail replay only — bounded by epoch writes, not accumulated state (DESIGN.md §11.5).
- [x] `proof_recovery_slo_minio_tc` — MinIO/TestContainers integration test; skipped if Docker unavailable (brownout path covers same S3 commit/replay code paths via SimObjectStore in its absence).

## Bounded Buffers & Queues

| Buffer / Queue | Upper Bound | Fill Metric | Backpressure |
|----------------|-------------|-------------|--------------|
| Kafka lag buffer | `LOCAL_BUFFER_MAX_EPOCHS * rows_per_epoch` | `kafka_lag_rows` vec length | Source credit-starved during brownout; credits restored on recovery |
| Recovery timing samples | `duration_ms / epoch_ms` samples max | `fd_ms.len()`, `sa_ms.len()`, `fr_ms.len()` | SimRuntime epoch loop bounded by `duration_ms` |
| Catchup sample buffer | Same epoch bound | `catchup_ms.len()` | Drains at 2× burst rate post-recovery |
