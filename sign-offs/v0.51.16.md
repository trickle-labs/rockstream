## Exit Criteria Verification

All Proof criteria in `NEW_ROADMAP.md` (v0.51.16, line 1061) were verified against `.claude/v0.51.16-evidence.md` and the release gates below.

### Proof Claims

- [x] **P1 — Real Postgres 18 snapshot, CDC, and LSN restart**: Real Postgres 18 Testcontainers proves snapshot initialization, keyed `INSERT`/`UPDATE`/`DELETE` Z-set deltas, and worker restart resuming strictly from committed LSN without duplicate emissions. Proven by `postgres_cdc_exactly_once_tests` (`real_pg18_lsn_restart_zero_duplicates`, `worker_restart_resumes_committed_lsn_with_exact_keyed_cdc_output`).
- [x] **P2 — `pgoutput` and `wal2json` format parity**: `pgoutput` and `wal2json` logical replication decoders produce exact positive and negative Z-set deltas across table operations. Proven by `postgres_cdc_format_matrix_tests` (`pgoutput_insert_produces_exact_positive_zset_delta`, `pgoutput_update_produces_retract_and_insert_zset_delta`, `pgoutput_delete_produces_exact_negative_zset_delta`, `wal2json_insert_produces_exact_positive_zset_delta`, `wal2json_update_produces_retract_and_insert_zset_delta`, `wal2json_delete_produces_exact_negative_zset_delta`).
- [x] **P3 — Invalidated-slot recovery via resnapshot**: Dropped or invalidated replication slots trigger clean worker reset and full table resnapshot recovery without data loss or stuck states. Proven by `postgres_cdc_failure_and_slow_subscriber_tests` (`real_pg18_slot_invalidation_recovery`, `slot_invalidated_triggers_resnapshot`).
- [x] **P4 — Slow-subscriber WAL lag backpressure**: High WAL lag and downstream backpressure pause replication slot consumption to bound buffer usage and prevent server memory exhaustion. Proven by `postgres_cdc_failure_and_slow_subscriber_tests` (`real_pg18_slow_subscriber_backpressure`, `slow_subscriber_pauses_reading`).
- [x] **P5 — Webhook reachability, RS-coded errors, JSON/CSV delivery, retry, 429 recovery, and live status**: HTTP webhook ingress provides authenticated JSON and CSV payload ingestion, commits deliveries to M3 before sending 202 responses, returns 429 when ingress buffers fill, and exposes live metrics through `SHOW SOURCE STATUS`. Proven by `source_ddl_postgres_webhook_tests`.
- [x] **P6 — Multi-backend parity across LFS, MinIO, SimRuntime, and TestContainers**: Durability, failover, fencing, and crash recovery run cleanly across LocalFileSystem, MinIO object storage, deterministic simulation, and real containerized Postgres 18. Proven by `source_durability_lfs_tests`, `source_durability_minio_tests`, and `source_coordination_sim_tests`.
