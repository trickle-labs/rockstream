# v0.4 Sign-off — Filter / Project / Map (IVM-1)

**Signed off**: 2026-06-07

## Scope recap

v0.4 implements the first IVM-1 operators: Z-set types (`ArrowZSet` with
per-row `Vec<i64>` weights), `PlanNode` additions (`ViewSink`, `Exchange`
stub), `DiffCtx` linear-operator rules (Filter, Project, Map, Source,
ViewSink, Exchange), the `Operator` trait + `EpochOutput`, `OperatorTask`
async event loop with credit-based backpressure, `CreditScheduler` (linear
chains), `ViewSinkOp` writing view_output to `ShardDb`, built-in
`VecDeltaSource` and `GenerateRowsSource`, `LinearPipeline` synchronous
combinator, and the embedded single-process runtime that issues **zero gRPC
calls** and creates **zero shuffle objects**.

New crates modified/implemented:
- `rockstream-plan`: `ViewSink`, `Exchange`, `ExchangeKind` added to `PlanNode` and `OpKind`.
- `rockstream-diff`: Full `DiffCtx` with linear-operator rules for Filter/Project/Map/Source/ViewSink/Exchange.
- `rockstream-ops`: All v0.4 operator modules (`zset`, `expr`, `filter`, `project`, `map`, `op`, `task`, `scheduler`, `source`, `sink`, `pipeline`, `embedded`).
- `rockstream-oracle`: `filter_oracle` module with oracle property tests (100k scenarios) and DataFusion validation.
- `rockstream-runtime`: Re-exports `EmbeddedRuntime` and `CreditScheduler`.

## Notes

- New modules in `rockstream-ops`: `zset` (ArrowZSet), `expr` (expression evaluator), `filter` (FilterOp), `project` (ProjectOp/NamedExpr), `map` (MapOp), `op` (Operator trait, EpochOutput), `task` (OperatorTask, OPERATOR_CHANNEL_CAPACITY), `scheduler` (CreditScheduler), `source` (VecDeltaSource, GenerateRowsSource), `sink` (ViewSinkOp, read_view_output), `pipeline` (LinearPipeline), `embedded` (EmbeddedRuntime, EmbeddedCounters).
- New module in `rockstream-oracle`: `filter_oracle` with oracle assertion, DataFusion validation, and 100k proptest cases.
- New crate implementation in `rockstream-diff`: `DiffCtx` with linear-operator rules for Filter, Project, Map, Source, ViewSink, Exchange.
- `rockstream-runtime`: Re-exports EmbeddedRuntime/CreditScheduler from rockstream-ops.
- `ExchangeKind` added to `rockstream-plan`: `Loopback` (only mode active in v0.4), `Hash`, `Broadcast`, `Single`, `Range`.
- The oracle property test validates the DBSP linear-operator rule `ΔF(Δx) = F(Δx)` at scale: 100k random delta sequences, mixed weights (+1, -1, +2), boundary cases (b*2 = 10 = exactly filtered, b*2 = 11 = passes).
- Deferred (out of scope for v0.4, by roadmap schedule): algebraic aggregates SUM/COUNT/AVG (v0.5); MIN/MAX (v0.6); crash-replay (v0.6); multi-shard exchange over gRPC (v0.16); group commit (v0.5).
