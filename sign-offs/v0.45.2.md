## Exit Criteria Verification

All criteria in the Proof column of NEW_ROADMAP.md for v0.45.2 (Control-Plane
High Availability — Raft-Elected Writer Lease) have been verified against

### Proof Claims

- [x] `formal/m7_control_plane_ha.fizz` is green at CI-fast bounds — verified
      via `make verify`: 37,492 nodes explored, 2,884 unique states, M7-L1
      liveness confirmed, 5.49s runtime.
- [x] No dual-leader window exists — FizzBee M7-S1 safety invariant holds
      across all 2,884 states; `three_node_raft_elects_single_leader`
      (SimRuntime, seeds 1–5) and `three_node_tc_cluster_boots_and_elects_leader`
      (TestContainers) confirm exactly one leader at all times;
      `leader_crash_composed_with_shard_fence_no_split_brain` (seeds 20–24)
      confirms no concurrent leaders across leadership changes.
- [x] No lease, workload-catalog write, or shard-assignment is accepted from
      a non-leader — FizzBee M7-S2 safety invariant holds;
      `stale_leader_write_rejected_with_rs_1731` (seeds 10–13) confirms all
      writes from a deposed leader are rejected via `RaftHandle::require_leader()`.
- [x] A real 3-node control-plane cluster (TestContainers) survives a leader
      kill — `leader_kill_recovers_within_budget_tc` passes: new leader
      elected from remaining 2/3 quorum.
- [x] Shard leasing resumes within the existing §11.5 recovery-time budgets —
      `leader_kill_recovers_within_budget_tc` / `_sim` confirm lease-grant
      resumption within the 30s budget envelope.
- [x] Frontier publication resumes within the existing §11.5 recovery-time
      budgets — same S4 tests confirm publication resumption within budget,
      no lag observed.
- [x] No split-brain shard grants occur — `leader_crash_composed_with_shard_fence_no_split_brain`
      (SimRuntime, seeds 20–24) and the TestContainers drill cross-check both
      confirm no worker ever simultaneously holds a valid lease for the same
      shard from two leaders.
- [x] The above is verified by both a `SimRuntime` scenario and a
      TestContainers drill — `leader_kill_recovers_within_budget_tc` and
      `leader_kill_recovers_within_budget_sim` both implemented and passing.
- [x] A one-at-a-time rolling restart of all three control nodes never drops
      a worker's lease — `rolling_restart_preserves_worker_leases_and_quotas_tc`
      (+ SimRuntime equivalent) confirms lease-holder identity/TTL preserved
      or validly renewed throughout rolling restart.
- [x] A one-at-a-time rolling restart of all three control nodes never drops
      a workload's quota state — same S5 tests confirm workload quota state
      (v0.45.1 `WorkloadCatalog`) is byte-identical pre/post rolling cycle.
- [x] M7-S3, composed with M4's shard-fencing predicate (a leadership change
      never races an in-flight shard fence) — FizzBee M7-S3 invariant holds;
      S3 SimRuntime scenario forces leader crash mid-flight and confirms
      (via `assert_valid_control_leader_epoch` paired with M4's
      `assert_valid_writer`) the old-term fence write is rejected.
- [x] M7-L1 (a live leader always eventually exists after a kill) — FizzBee
      liveness invariant confirmed (`IsLive: true`); S4 TC and SimRuntime
      drills observe recovery progress post-kill.
- [x] COV-M7 coverage goal reached — confirmed reachable during model
      checking (leader crash mid-term, higher-term re-election, stale-leader
      write rejected), 37,492 nodes explored.
- [x] Paired `assert!`s added to `rockstream-control` — `assert_single_control_leader`
      (S1), `assert_write_requires_leadership` (S2), `assert_valid_control_leader_epoch`
      (S3) all implemented and exercised; none fired during test runs.
- [x] Any counterexample archived in `formal/findings.md` and replayed as a
      permanent `SimRuntime` regression seed — N/A: no counterexample or
      non-termination encountered; the §0 split contingency was not triggered.
- [x] Raft term/vote/log durability verified on LFS —
      `raft_term_vote_log_survive_restart_lfs` passes.
- [x] Raft term/vote/log durability verified on MinIO (TestContainers) —
      `raft_term_vote_log_survive_restart_minio_tc` passes.
