# v0.2 Sign-off — Runtime abstraction, simulation, and oracle

**Signed off**: 2026-06-07

## Scope recap

v0.2 implements the `rockstream-sim` runtime abstraction (`Runtime` trait,
`TokioRuntime`, seeded `SimRuntime`, `buggify!()` macro, fault-model registry,
paired-assertion helper) and the `rockstream-oracle` crate (DataFusion batch
reference engine + `proptest` harness asserting `incremental == batch`).

The `rockstream-sim` crate was established at v0.1 with full implementation.
The `rockstream-oracle` crate was an empty scaffold at v0.1; v0.2 fills it
with the Z-set accumulation module (`zset.rs`), the DataFusion batch reference
engine (`batch.rs`), and the oracle harness + proptest property test
(`harness.rs`).
