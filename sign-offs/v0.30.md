# v0.30 Sign-off — Auto-Tuner Chaos Soak

**Signed off**: 2026-06-19  
**Version focus**: Subject the cluster to extreme step-function traffic spikes to test the default "self-tuning" adaptive control loops (epoch sizing, source throttling, and parallelism); prove control loops do not overcorrect and enter destabilizing oscillation.

---

## Proof Claims

**Roadmap proof statement:** Control loops settle to a stable steady-state within 3 epochs of a 10× traffic spike.

### P1 — Control loops settle to stable steady-state within 3 epochs of 10× traffic spike

- [x] `proof_auto_tuner_combined_settles_within_3_epochs` — SpikeScenario runs 10× step-function spike (5 baseline epochs + 10 spike epochs). All three control loops (epoch sizing, parallelism, source throttle) applied per epoch. Asserts `epochs_to_settle.unwrap() <= 3`.
- [x] `proof_auto_tuner_buggify_chaos_1000_seeds_all_settle` — 1,000 buggify seeds all settle within 3 epochs with no panic.

**Reproduce:**
```bash
rtk cargo test --lib spike::tests::proof_auto_tuner_combined_settles_within_3_epochs
rtk cargo test --test auto_tuner_chaos_tests proof_auto_tuner_buggify_chaos_1000_seeds_all_settle
```

### P2 — Epoch sizing loop specifically settles within 3 adjustments

- [x] `proof_epoch_sizer_settles_within_3_adjustments_under_10x_spike` — Epoch sizing loop called 4 times under 10× write_rate spike. Results differ on call 1, identical by call 2. Final state: (5000, 5000). Audit events recorded for every adjustment.

**Reproduce:**
```bash
rtk cargo test --lib auto_tuner::tests::proof_epoch_sizer_settles_within_3_adjustments_under_10x_spike
```

### P3 — Parallelism loop settles without oscillation

- [x] `proof_parallelism_loop_settles_within_3_adjustments_no_oscillation` — Hysteresis counters (scale-up after 3 windows, scale-down after 12) prevent oscillation. Trace [4, 4, 5, 5, 5, 5, 5] has zero direction reversals.
- [x] `proof_parallelism_trace_no_oscillation` — Real parallelism trace from SpikeScenario fed into OscillationDetector; returns `false` (no oscillation).

**Reproduce:**
```bash
rtk cargo test --lib auto_tuner::tests::proof_parallelism_loop_settles_within_3_adjustments_no_oscillation
rtk cargo test --test auto_tuner_chaos_tests proof_parallelism_trace_no_oscillation
```

### P4 — Source throttle settles without deadlock

- [x] `proof_source_throttle_settles_within_3_adjustments_no_deadlock` — 100 calls under sustained lag trigger 3 throttle halvings (512→256→128→64). Never returns 0. Always >= MIN_THROTTLE_BYTES (64). Settles at floor after 3 reductions.

**Reproduce:**
```bash
rtk cargo test --lib auto_tuner::tests::proof_source_throttle_settles_within_3_adjustments_no_deadlock
```

### P5 — No oscillation in any trace after spike

- [x] `proof_oscillation_detector_catches_synthetic_oscillation` — OscillationDetector correctly identifies [1.0, 3.0, 1.0, 3.0] as oscillating (2 direction reversals within window of 4).
- [x] `proof_oscillation_detector_passes_monotone_series` — OscillationDetector correctly passes [1.0, 2.0, 3.0, 4.0] as non-oscillating.
- [x] `proof_parallelism_trace_no_oscillation` — Real spike trace passes detector (no false positives).

**Reproduce:**
```bash

rtk cargo test --test auto_tuner_chaos_tests proof_oscillation_detector_passes_monotone_series
rtk cargo test --test auto_tuner_chaos_tests proof_parallelism_trace_no_oscillation
```

### P6 — Oracle property: incremental == batch

No information loss in incremental control loop.

**Reproduce:**

|----------------|-------------|-------------|--------------|
| Parallelism up-window counter | `hysteresis_scale_up_windows` (default 3) | `up_window_count` | Stops at bound; no further accumulation |
| Parallelism down-window counter | `hysteresis_scale_down_windows` (default 12) | `down_window_count` | Stops at bound; no further accumulation |
