## Exit Criteria Verification

- [ ] V066-01: `CreateBackup` has no executor or durable checkpoint-manifest path; the management RPC returns `UNAVAILABLE`. Drain and migration evidence does not yet prove successful real worker-side shard movement and recipient acknowledgement.
- [ ] V066-02: No standalone and multi-process before/after matrix proves every displayed field follows its real state owner. Current status tests cover a single empty node.
- [ ] V066-03: Operation records cover acceptance, recovery, and cancellation cases, but the full six-state transition and truthful executor-outcome matrix is incomplete.
- [ ] V066-04: Durable idempotency is tested, but production executor effects have not been tested across server kill/restart or concurrent cross-process retries; management mutations also lack leader fencing.
- [ ] V066-05: Operation-store reopen and storage-failure tests pass, but there is no management backup effect and no kill-before/after-effect reconciliation proof for production mutations.
- [ ] V066-06: Safe-boundary cancellation checks pass, but real executor interruption and retained-data checks at each irreversible boundary are missing.
- [ ] V066-07: Named page, request, and operation bounds exist, but deterministic pressure, expiry, cleanup, and recovery evidence does not cover every queue, waiter, and cross-process admission path.
- [ ] V066-08: The CLI uses management RPC for the covered routes, but release-process transcripts for standalone and multi-process clusters, complete example execution, and secret-free output proof are missing.
