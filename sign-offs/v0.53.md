## Notes

All exit criteria for v0.53 have been successfully implemented and verified:

### Shard Column Statistics (OLAP Scatter Pruning)

- **`ColumnMinMax`**: Per-column min/max bounds (big-endian encoding) for range-predicate pruning. `could_contain_eq` returns `false` only when value is definitely outside bounds — no false negatives.
- **`BlockedBloomFilter`**: Deterministic blocked Bloom filter with 64 KB budget (512k bits) per column per shard. Uses FNV-1a double-hash with k=3 hash functions. Guaranteed no false negatives. Proven by `bloom_no_false_negatives_10k` test (10k values, all must be found).
- **`HllCardinality`**: HyperLogLog sketch with 12-bit precision (4096 registers, ≈±1.6% error) for cardinality estimation in the planner cost model. Mergeable via per-register max.
- **`ShardColumnStats`**: Aggregate per-shard, per-column container. `insert()` updates all three structures atomically.
- **`ShardStatsRegistry`**: In-process registry for scatter pruning. `prune_scatter()` applies min/max + Bloom checks per shard. Detects staleness via `published_at_ms` + `max_age_ms`.

### Proof Criteria Verified

- **100-shard/8-match scatter test**: `scatter_pruning_100_shards_8_match_at_most_12_survive` verifies ≤ 12 shards survive pruning when exactly 8 shards contain the target value. Min/max prunes 92 shards definitively.

### Security Review Triage

Security review was conducted on all new v0.53 code:
- `shard_stats.rs`: No networked I/O; all computation is local. The Bloom filter uses deterministic hashing (FNV-1a + Murmur3 finalizer) with no cryptographic claims. The HLL sketch uses the same hash family. No untrusted input is evaluated as code. The `ShardStatsRegistry` does not expose raw bytes from external sources to unsafe code paths.
- `StorageFormatVersion`: Acts as a fail-closed gate — incompatible versions are rejected before any data is read. No bypass paths.
- `rockstream inspect stats`: CLI tool performs only read operations on local filesystem paths. No network calls.
- No new authentication surfaces, no new external connections, no new deserialization of untrusted data across the network.
- No known security issues identified. Triage: **green**.
