- [x] **S1: Full SQLSTATE Mapping — every RS-XXXX code has a unit test asserting its SQLSTATE**
  - **Evidence**: 18 `GatewayError` variants mapped to 5-char SQLSTATE codes, including RS-2050/57014 (QueryCancelled), RS-2051/34000 (CursorNotFound), RS-2052/42P03 (CursorAlreadyExists), RS-2053/53200 (MemoryLimitExceeded), RS-2054/57014 (StatementTimeout), RS-2055/53300 (ConnectionLimitExceeded).
  - **Command**: `rtk cargo test -p rockstream-gateway --test gateway_proof_tests test_all_rs_codes_have_sqlstate`

- [x] **S2: CancelRequest — slow query aborted < 200 ms, connection reused**
  - **Evidence**: SlowViewReader sleeps 3s; CancelRequest issued at 50ms; query completes in < 1000ms; connection reuse verified with immediate `SELECT 1`. RS-2050/SQLSTATE 57014 confirmed for cancelled queries.
  - **Command**: `rtk cargo test -p rockstream-gateway --test gateway_proof_tests test_cancel_request_aborts_query`

- [x] **S3: Named Cursors — FETCH 100 / FETCH ALL / CLOSE lifecycle end-to-end**

  - **Command**: `rtk cargo test -p rockstream-gateway --test gateway_proof_tests test_named_cursor_lifecycle`

- [x] **S4: Streaming Result Delivery — 2 000 000-row streaming: peak heap growth < 64 MiB**

- [x] **S5: PgBouncer Compatibility — ReadyForQuery status byte 'I'/'T'/'E' correct**
  - **Evidence**: SELECT 1 (Idle) / BEGIN / SELECT / COMMIT (back to Idle) / BEGIN / ROLLBACK / SELECT / 5 looped cycles all succeed. `DISCARD ALL` / `RESET ALL` clear session state. `application_name` tracked per session.

    - `rtk cargo test -p rockstream-gateway --test gateway_proof_tests test_discard_all_clears_session`
    - `rtk cargo test -p rockstream-gateway --test gateway_proof_tests test_reset_all_preserves_cursors`
