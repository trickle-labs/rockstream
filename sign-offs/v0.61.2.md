## Exit Criteria Verification

All exit criteria from [v0.61.2 implementation plan](../docs/implementation-plans/v0.61.2.md) have been verified:

- [x] V0612-01: SUM and COUNT emit exactly the old negative row and final positive row for a changed group, and no rows for unchanged output. Staged epoch consolidation suppresses intermediate deltas and unchanged transitions; proven by `delta_native_aggregate_tests::test_v0612_repeated_updates_emit_old_and_final_only`, `delta_native_aggregate_tests::test_v0612_unchanged_aggregate_emits_no_delta`, and `delta_native_aggregate_tests::test_v0612_multi_value_cancellation_emits_no_delta`.
- [x] V0612-02: Deletions, NULL-only groups, signed multiplicities, and group recreation retain existing SQL results. Group deletion emits retraction and `StateMutation::Delete` tombstone; group recreation emits insertion and `Put`; NULL rows and zero weights are ignored without state modification; proven by `delta_native_aggregate_tests::test_v0612_group_deletion_emits_retraction_and_tombstone`, `delta_native_aggregate_tests::test_v0612_group_recreation_after_deletion`, `delta_native_aggregate_tests::test_v0612_signed_multiplicity_scaling`, and `delta_native_aggregate_tests::test_v0612_null_and_zero_weight_handling`.
- [x] V0612-03: Overflow, invalid input, and accumulator exhaustion leave the whole epoch uncommitted and previous state intact. Staged validation rejects multiplication overflow (`RS-2001`), sum overflow (`RS-2001`), negative multiplicity (`RS-2003`), and schema errors (`RS-2001`) with zero partial state mutation to operator memory or dirty keys; proven by `delta_native_aggregate_tests::test_v0612_multiplication_overflow_atomicity`, `delta_native_aggregate_tests::test_v0612_sum_overflow_atomicity`, `delta_native_aggregate_tests::test_v0612_invalid_multiplicity_atomicity`, and `delta_native_aggregate_tests::test_v0612_malformed_schema_atomicity`.
- [x] V0612-04: Multiple observable epochs remain separate even when physically batched, and input batch boundaries do not change one epoch's result. Partitioned transport batches produce identical multisets to monolithic batches within an epoch; distinct epochs advance visibility frontiers separately without cross-epoch coalescing; proven by `delta_native_aggregate_tests::test_v0612_monolithic_vs_split_batches_match`, `delta_native_aggregate_tests::test_v0612_distinct_epochs_never_coalesce`, and `sim_aggregate_consolidation_tests::test_sim_aggregate_epoch_consolidation_under_network_loss`.
- [x] V0612-05: Dirty-key writes remain proportional to affected keys and intermediate rows decrease for repeated-key updates. Hot-path single-key repeated updates reduce from $2N$ intermediate rows to exactly 2 output rows and 1 dirty key `Put`; full-state visited entries remain 0 across 1K, 100K, and 10M scales; proven by `constant_write_amplification_scale_tests::test_v0612_repeated_keys_intermediate_rows_reduction`, `constant_write_amplification_scale_tests::test_v0612_dirty_keys_proportional_to_distinct_keys`, `constant_write_amplification_scale_tests::test_constant_write_amplification_across_scales`, and `r1_execution_counter_tests::test_v0612_execution_counters_reflect_reduced_deltas`.
- [x] V0612-06: Crash and retry recover the exact acknowledged results without duplicate deltas or resurrected groups. Spawns release binary `rockstream`, executes repeated-key transactions, abruptly kills the process (`kill -9`), restarts against same storage directory, verifies pre-crash bit-identical recovery and post-restart transaction accumulation on both LFS and MinIO; proven by `aggregate_crash_recovery_tests::test_v0612_public_release_aggregate_crash_recovery`, `live_exec_aggregate_durability_lfs_tests::test_v0612_aggregate_persists_across_restart_lfs`, and `live_exec_aggregate_durability_minio_tests::test_v0612_aggregate_persists_across_restart_minio`.
- [x] V0612-07: Consolidation memory has named limits, observable occupancy, and deterministic overflow behavior. `MAX_EPOCH_CONSOLIDATION_GROUPS` (1,000,000) and `MAX_EPOCH_CONSOLIDATION_BYTES` (64 MiB) fail closed with `OpError::CapacityExceeded` (`RS-2002`); `consolidation_groups()` and `consolidation_bytes()` report observable occupancy; proven by `delta_native_aggregate_tests::test_v0612_consolidation_group_limit_enforced`, `delta_native_aggregate_tests::test_v0612_consolidation_byte_limit_enforced`, and `delta_native_aggregate_tests::test_v0612_consolidation_occupancy_is_observable`.
