## Notable scope decisions

- Full implementation and proof for all 14 admitted data types across 8 operational domains (`INT2`, `INT4`, `INT8`, `FLOAT4`, `FLOAT8`, `DECIMAL(p,s)`, `BOOLEAN`, `TEXT`, `VARCHAR`, `BYTEA`, `DATE`, `TIMESTAMP`, `TIMESTAMPTZ`, `INTERVAL`, `UUID`, `ARRAY`).
- Enforced `rockstream_binary_v1` UTF-8 byte order and 16-byte fixed UUID binary order for SlateDB index arrangements.
- Enforced checked integer arithmetic and arbitrary-precision `DECIMAL(p,s)` up to 38 digits failing closed with `RS-1016` (SQLSTATE `22003`) on overflow.
- Verified strict ANSI 3VL truth tables and null preservation across scalar, arithmetic, and logical operators.
- Implemented 1-dimensional array parameter binding and scalar-in-array membership evaluation `col = ANY($1)` over simple and extended query protocols.
- Verified fail-closed error codes for all unsupported operations (`RS-1019` for floating-point joins, `RS-1021` for interval joins, `RS-1012` for invalid syntax/casts, `RS-1013` for collations, `RS-1015` for incompatible conversions).
