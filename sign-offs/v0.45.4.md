### Proof Claims

- [x] **P1 — Deliberate 15% slowdown fails the gate (per subsystem)**: A
  deliberate 15% slowdown in any benchmark fails the regression gate for all
  four subsystems (ops, storage, runtime, control). Evidence:
  `test_regression_gate_fails_on_15pct_slowdown` (S7.1) in
  `crates/rockstream-ops/src/bench_regression.rs:164` proves the shared
  comparator's threshold logic (baseline 100ns vs. observed 115ns → fails);
  the single shared `bin/bench_regression_gate.rs` implementation is reused
  identically by all four CI steps (S2–S5), so this proves the gate for all
  four subsystems at once.
  `test_benchmark_ci_job_exists_and_covers_four_subsystems` in
  `crates/rockstream-gateway/tests/conformance_doc_tests.rs:524` confirms each
  subsystem's CI step invokes the binary with its own `--tag` and baseline
  file. Both tests pass (`.claude/v0.45.4-evidence.md` §P1).
- [x] **P2 — Reviewed improvement updates baseline idempotently**: After a
  reviewed improvement faster than baseline, `make bench-baseline-update`
  refreshes the baseline and re-gating still passes; the update step stays
  explicit/human-triggered, never auto-invoked by CI. Evidence:
  `test_bench_regression_gate_reads_baseline_update_makes_it_pass` (S7.2) in
  `bench_regression.rs:193` proves the update-then-regate cycle is idempotent;
  `test_makefile_has_bench_baseline_update_target_not_invoked_by_ci` (S7.4) in
  `conformance_doc_tests.rs:592` proves `Makefile` has the
  `bench-baseline-update` target and the literal string never appears in
  `.github/workflows/ci.yml`. Both tests pass (`.claude/v0.45.4-evidence.md`
  §P2). Baseline files checked in for all four subsystems: `ops` (9 ids),
  `storage` (3 ids), `runtime` (3 ids), `control` (3 ids).
- [x] **P3 — Job completes within a documented, bounded wall-clock budget**:
  The `benchmark` CI job (`.github/workflows/ci.yml:307–336`) carries an
  explicit `timeout-minutes: 25`, sized above the measured ~3m35s sum of the
  four `cargo bench --noplot` steps (warm cache: ops 1m55s, storage 0m36s,
  runtime 0m27s, control 0m37s), while staying tighter than the existing
  single-bench Nexmark job's 30-minute budget.
  `test_benchmark_ci_job_exists_and_covers_four_subsystems` asserts the
  `timeout-minutes` key is present and numeric. Evidence:
  `.claude/v0.45.4-evidence.md` §P3.
