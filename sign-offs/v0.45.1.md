## Notes

- New production subsystems: `crates/rockstream-gateway/src/admission.rs`
  (AdmissionController), `crates/rockstream-sql/src/workload_catalog.rs`
  (durable `WorkloadCatalog`), plus supporting changes to `workload.rs`
  (`max_parallelism` field), `view_lifecycle.rs` (`ViewState::OverBudgetRelaxed`),
  `error_code.rs` (new admission-control `RS-XXXX` codes), `keys.rs`
  (`CatalogType::Workload`), `server.rs` (DDL dispatch + admission controller
  wiring), `catalog_stubs.rs` (write-through + per-workload budget
  enforcement), `catalog.rs` (durable load/persist), `auto_tuner.rs`
  (`new_for_workload()`).
- New regression seed: `rockstream-sim/tests/workload_admission_control.rs`
  is a seeded `SimRuntime` test (F1 contention scenario) as required for new
  distributed-coordination paths.
- Every user/operator-visible failure introduced in this version (workload
  quota violations, admission-control rejections, DDL parse/validation
  errors) uses an `RS-XXXX` error code with actionable text.
- Nothing deferred: all 9 Proof claims (P1–P9) from the v0.45.1 roadmap row
  are implemented and verified in this sign-off. See
  `.claude/v0.45.1-evidence.md` for the full claim-by-claim test mapping.
