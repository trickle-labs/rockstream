## Notes

- NULL sentinel is `0i64` in output schema. Oracle tests use right values in `[1,10)` to
  avoid ambiguity with the NULL sentinel; this is documented in the oracle code.
- `RightSemi`, `RightAnti`, `LeftMark`, `RightMark` DataFusion join types are mapped to
  RS-1013 (not required for TPC-H coverage).
- RIGHT JOIN and FULL OUTER JOIN operators are fully implemented but have no dedicated
  oracle proptest (only deterministic unit tests); the LEFT/Semi/Anti oracle coverage
  provides confidence via the shared algorithm structure.
