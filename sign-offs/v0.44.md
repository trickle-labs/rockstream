# v0.44 Sign-off

**Signed off**: 2026-06-01

## DML Hardening: Transactions and DDL

All exit criteria for v0.44 are satisfied.

### Checklist

- [x] `cargo test --workspace` passes

- [x] **Idempotency enforcement — `RS-2007` on missing keys** —
  `proof_non_idempotent_write_missing_both_returns_rs_2007` in
  `rockstream-gateway::dml::tests` proves that a write submitted without an
  idempotency key when one is required returns `GatewayError` with
  `error_code() == RS_2007` (2007, "Non-idempotent write: idempotency key
  required"). `proof_idempotency_key_handles_replays` proves that a duplicate
  write carrying the same idempotency key is deduplicated rather than
  double-applied.

- [x] **1M concurrent counter increments with idempotency keys land exact total**
  — `proof_1m_concurrent_counter_increments_with_idempotency_keys_land_exact_total`
  in `rockstream-gateway::dml::tests` simulates 1 000 000 concurrent increment
  writes, each carrying a unique idempotency key, and asserts the final counter
  total equals exactly 1 000 000 — proving that idempotency-key deduplication
  does not under-count under high concurrency.

- [x] **Write-fence tokens coordinate producer/consumer** —
  `proof_write_fence_coordinates_producer_consumer` in
  `rockstream-gateway::freshness::tests` proves that `generate_write_fence`
  produces a `FreshnessToken` whose epoch exceeds the consumer's last-seen
  epoch, allowing a downstream reader to await that fence before serving a
  read, guaranteeing read-your-writes across a producer/consumer boundary.

- [x] **Background DDL returns immediately** —
  `proof_set_background_ddl_returns_immediately` in
  `rockstream-gateway::inline_view::tests` proves that submitting a DDL
  statement with `NO WAIT` mode returns control to the caller before the
  operation completes. `proof_wait_for_view_to_be_ready_success` and
  `proof_wait_for_view_to_be_ready_timeout` prove that `WAIT` mode blocks
  until the view is `Ready` or surfaces a timeout error respectively.

- [x] **Zero-downtime replacement swaps view routing atomically without disconnect**
  — `proof_zero_downtime_replacement_swaps_view_routing` in
  `rockstream-gateway::inline_view::tests` proves that `CREATE REPLACEMENT VIEW`
  atomically swaps the routing entry for the old view to point at the new view
  definition without a window of unavailability: the router never returns
  `NotFound` between the tear-down of the old view and the activation of the
  replacement.

- [x] **Namespace commands audit successfully** —
  `proof_namespace_commands_audit_successfully` in
  `rockstream-gateway::inline_view::tests` proves that `CREATE NAMESPACE` and
  `DROP NAMESPACE` each emit an audit event with the correct namespace name and
  operation type, and that the audit log contains exactly the expected entries
  after both commands are executed.

- [x] **ROADMAP.md status updated to `✅ Done`**
