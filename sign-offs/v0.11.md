### Claim 2 — Partition-recompute cost is measured and documented

**2a.** Unit test `window_partition_recompute_cost_bounded` (rockstream-ops):
```
cargo test -p rockstream-ops window_partition_recompute_cost_bounded
test result: ok. 1 passed; 0 failed; 0 ignored; 0 measured; 131 filtered out
```

**2b.** Oracle harness cost-ratio assertions (50k random epochs) confirm ratio bounded by affected partition sizes:
```
oracle cost: recomputed_rows=39  delta_rows=21  ratio=1.86  max_part=8
oracle cost: recomputed_rows=59  delta_rows=29  ratio=2.03  max_part=12
oracle cost: recomputed_rows=0   delta_rows=1   ratio=0.00  max_part=0
```
All 50k cases pass the cost assertion. Unchanged partitions are not recomputed (ratio = 0).

**2c.** Module docstring in `crates/rockstream-ops/src/window.rs` documents:
- Recomputation cost per epoch = Σ_{affected P} O(|P| × log|P|)
- Only partitions with at least one row in the input delta recompute
- `WINDOW_PARTITION_THRESHOLD = 10_000` rows
- `fill_level()` and `oversized_partition_keys()` expose metrics

- [x] **Claim 2 verified**: Cost measured (unit test + oracle ratio assertions) and documented (module docstring).
