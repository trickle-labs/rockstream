# v0.42 Sign-off

## Freshness, subscribe, isolation, historical and monotone-partial queries

All exit criteria for v0.42 are satisfied.

### Checklist

- [x] **Read-your-writes demo passes** — `proof_read_your_writes_demo` in
  `rockstream-gateway::freshness::tests` proves that a write recorded at epoch
  10 against a committed frontier of 10 returns `WaitForOutcome::Ready`, and
  against a frontier of 7 returns `WaitForOutcome::WouldBlock { required: 10,
  current: 7 }`.

- [x] **Subscribe stream survives gateway restart without gaps or duplicates** —
  `proof_subscribe_survives_restart_without_gaps_or_duplicates` in
  `rockstream-gateway::subscribe::tests` proves that a `SubscribeCursor` that
  delivered epochs 1–5 (last cursor epoch = 5) resumes from epoch 6 on restart
  via `cursor.resume_options()` and receives exactly the rows for epochs 6–10
  with no duplicates and no gaps.

- [x] **`SELECT * FROM orders_mv AS OF EPOCH <past>` returns the correct
  historical snapshot** — `proof_as_of_epoch_returns_correct_snapshot` in
  `rockstream-gateway::historical::tests` proves that `HistoricalAsOf::Epoch(10)`
  returns 2 rows, `Epoch(20)` returns 3 rows, and `Epoch(30)` returns 4 rows,
  matching the deterministic snapshot set.

- [x] **`AS OF MONOTONE PARTIAL` returns a result with an explicit
  `complete_through` token for a monotone reachability view** —
  `proof_monotone_partial_returns_complete_through_token` in
  `rockstream-gateway::historical::tests` proves that
  `execute_monotone_partial` returns a `MonotonePartialResult` with
  `complete_through = 30` and `is_complete = true` when `current_epoch == 30`.

- [x] **Queries beyond retention return RS-2006** —
  `proof_beyond_retention_returns_rs_2006` in
  `rockstream-gateway::historical::tests` proves that querying epoch 10 when
  `current_epoch = 40` and `checkpoint_retention_count = 5` (oldest retained =
  35) returns `GatewayError::HistoricalQueryBeyondRetention` with `error_code()
  == RS_2006` (2006, "Historical query beyond checkpoint retention window").
  **Note**: the ROADMAP.md exit criterion text says "RS-2005" but RS-2005 is
  already registered as "Query rate limit exceeded" (v0.40). RS-2006 is the
  correct code for "Historical query beyond checkpoint retention window".

- [x] **`SUBSCRIBE orders_mv AS OF NOW WITH SNAPSHOT` delivers current state
  then live deltas** —
  `proof_subscribe_now_with_snapshot_delivers_snapshot_then_deltas` in
  `rockstream-gateway::subscribe::tests` proves that a `SubscribeBatch` for
  `NowWithSnapshot` from epoch 0 to epoch 3 delivers the cumulative snapshot
  rows followed by rows for epochs 1–3 with correct `mz_diff` values.

- [x] **`SUBSCRIBE ... WHERE region = 'us-east'` reduces network traffic to
  matching rows only** — `proof_subscribe_where_predicate_reduces_rows` in
  `rockstream-gateway::subscribe::tests` proves that a subscribe with
  `WHERE region = 'us-east'` (2 matching rows out of 4) returns only those 2
  rows in the batch.
