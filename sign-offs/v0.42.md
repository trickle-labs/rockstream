## Fixes Applied During Prove Phase

1. **Host network reachability** — Changed gateway bind to `127.0.0.1:0`; container DSN host set to `host.docker.internal`.
2. **PipelineOwner ACL grant** — Grant `PipelineOwner` role on `public` namespace to `alice` in `spawn_smoke_gateway()` and `spawn_ref_gateway()`.
3. **DataFusion literal SELECT executor** — Added `try_datafusion_select()` method for literal SELECT queries (e.g. `SELECT 42`).
4. **`describe_fields_for_query` fallback** — Static analysis fallback using `infer_select_columns` so RowDescription column count matches DataFusion result.
5. **Extended query parameter substitution** — Added `substitute_params()` for `$1..$N` placeholders before DataFusion dispatch.
6. **Transaction CommandComplete tags** — Removed erroneous `.with_rows(0)` from `BEGIN`/`COMMIT`/`ROLLBACK`/`SAVEPOINT`/`RELEASE`; golden blobs regenerated.
7. **PgJDBC container** — Changed from `eclipse-temurin:21-jre-alpine` to `21-jdk-alpine` for Java source-file launching.
8. **Java smoke snippet** — Added `import java.util.Properties;` to fix compilation.
9. **COPY FROM STDIN in psql** — Removed live COPY data test from psql script (COPY wire protocol proven by `test_golden_wire_copy_in`).
