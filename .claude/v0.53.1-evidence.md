## 4. Error Code & Safeguard Matrix

| Error Code | Meaning | Trigger Scenario | Documented Remedy | Status |
|---|---|---|---|---|
| `RS-0005` | Destructive command confirmation required | Destructive CLI command executed non-interactively without `--yes` | Pass `--yes` for scripted execution or respond `y` at the prompt | **VERIFIED** |
| `RS-1001` | Entity not found | Dropping or querying non-existent view or schema | Inspect names with `rockstream view list` or `rockstream schema list` | **VERIFIED** |
| `RS-1004` | Entity already exists | Creating schema/table that already exists | Use distinct name or inspect with `rockstream schema show` | **VERIFIED** |
| `RS-1005` | Workload not found | Altering or dropping non-existent workload | Inspect workloads with `rockstream workload list` | **VERIFIED** |
| `RS-1006` | Workload already exists | Creating an existing workload | Use distinct name or modify existing with `workload alter` | **VERIFIED** |
| `RS-1007` | View already paused | Pausing a view that is currently in PAUSED state | Check view status with `rockstream view status` | **VERIFIED** |
| `RS-1008` | View not paused | Resuming a view that is already RUNNING | Check view status with `rockstream view status` | **VERIFIED** |
| `RS-1014` | Workload drop rejected | Attempting to drop workload with assigned views | Reassign or drop dependent views first | **VERIFIED** |
| `RS-2006` | Epoch before retention | Subscribing from epoch outside retention window | Subscribe with `--snapshot` or more recent epoch | **VERIFIED** |
| `RS-2401` | Permission denied | Principal lacks required RBAC role | Request elevated RBAC role (PipelineOwner / Admin) | **VERIFIED** |
| `RS-4009` | Source not found | Pausing, resuming, or dropping non-existent source | Inspect sources with `rockstream source list` | **VERIFIED** |
| `RS-5030` | In-flight migration conflict | Re-issuing shard migration while migration is in progress | Wait for active migration to complete or inspect status | **VERIFIED** |
