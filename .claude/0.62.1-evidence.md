## 2. Exit Criteria Verification

### V0621-01: Production Shard Construction & Shared Cache Injection
- **Requirement**: Every production shard creation path receives the worker-owned caches and shared allocations are charged once.
- **Evidence**:
  - `shard_construction_tests::test_every_production_shard_receives_shared_storage_context`: Asserts that production shard builder injects `WorkerStorageContext`, sharing block and metadata caches across all shards.
  - `shard_construction_tests::test_shared_cache_allocations_charged_once_across_shards`: Verifies that shared cache memory is charged exactly once on the `WorkerBudgetLedger` regardless of how many shards are opened or attached.
  - `shard_construction_tests::test_cache_key_isolation_across_tenants_and_arrangements`: Proves multi-tenant cache keys are strictly isolated by tenant ID, policy digest, arrangement ID, and block index.
  - Production call-site inventory:
    - `crates/rockstream-runtime/src/client.rs:807`: Worker client startup injects `WorkerStorageContext`.
    - `crates/rockstream-runtime/src/client.rs:914`: Shard restoration injects `WorkerStorageContext`.
    - `crates/rockstream-cli/src/lib.rs:362`: CLI gateway / standalone startup injects `WorkerStorageContext`.
    - `crates/rockstream-cli/src/component.rs:133-157`: `WorkerComponent` initializes and owns shared `WorkerStorageContext` and `WorkerBudgetLedger`.

### V0621-03: Source Pressure Propagation & Waiter Queue Bounding
- **Requirement**: Pressure reaches sources and retries, waiters, and queue age remain within frozen limits under sustained overload.
- **Evidence**:
  - `source_pressure_propagation_tests::test_source_credits_reduced_at_eighty_percent`: When memory reaches 80% of budget, CDC source poll credits and ingest batch sizes scale down to 50%.
  - `source_pressure_propagation_tests::test_source_paused_at_ninety_five_percent`: When memory reaches 95% of budget, source poll loops pause and return backpressure refusal (`RS-5003` / `RS-4029`).
  - `source_pressure_propagation_tests::test_source_resumes_when_pressure_clears`: When memory drops below 75%, source poll credits resume to 100%.
  - `memory_bounding_tests::test_allocation_waiters_queue_strictly_bounded`: The allocation waiter queue is strictly capped at 1,024 entries; incoming requests beyond capacity fail with `RS-9001`.
  - `memory_bounding_tests::test_allocation_waiter_timeout_enforced`: Allocation waiters enforce a strict 1.0s maximum queue age; waiters exceeding deadline time out with `RS-5003`.
- **Command Output**:
  ```
  cargo test -p rockstream-runtime --test source_pressure_propagation_tests: 3 passed (1 suite, 0.00s)
  cargo test -p rockstream-runtime --test memory_bounding_tests: 5 passed (1 suite, 0.05s)
  ```
