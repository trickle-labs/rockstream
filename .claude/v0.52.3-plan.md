## 4. Vertical slices

1. **Error contract.** Add `RS-4017 connector.removed` to the central registry
   (`slug`, description, severity, next steps, registry enumeration) and
   `scripts/check-error-codes.sh` plus its paired script test. Green gate:
   `error_code::all_codes_have_descriptions_and_actionable_next_steps` and
   `check-error-codes.test.sh` accept the exact code.
2. **Fail-closed DDL.** Add one shared removed-connector classification guard
   at the existing gateway dispatcher/handler boundary, ahead of current
   `RS-4007`/`RS-4008` validation. Cover the complete removed DDL matrix via a
   new raw-pgwire `connector_removal_tests.rs`; prove simple and extended
   protocol responses are identical.
3. **Fail-closed webhook ingress and CLI config.** Reject webhook HTTP before
   lookup or durable input write, and reject all populated tiering fields at
   CLI config validation. Green gates are the exact endpoint body/status and
   the exact `CliError` respectively; the normal `rockstream` binary remains
   runnable when those removed settings are absent.
4. **Visible legacy catalog state.** Add the smallest versioned persisted
   connector-catalog record/load path required for source/sink metadata;
   normalize removed connector records to `REMOVED` with `RS-4017` on load.
   Add `SHOW SINKS` alongside the existing `SHOW SOURCES` path. The load is a
   bounded catalog-key read, never a range deletion or unbounded scan.
5. **Durable upgrade proof.** Seed v0.52.2-format rows and prove clean restart
   plus exact `SHOW` output on LFS and MinIO TestContainers. No SlateDB range
   delete is added; tests assert the storage mock/trace sees no range-delete
   operation.
6. **Documentation and drift lock.** Update `README.md`, `docs/concepts.md`,
   `docs/language-features.md`, and `docs/configuration.md`; add
   `docs/connector-migration.md` with the exact external-loader, HTTP adapter,
   and Kafka-downstream-writer replacements. Add the Removed table and extend
   the existing documentation conformance test to reject live references to a
   removed connector outside that table and migration page. Green gate:
   `connector_removal_docs_have_exact_replacements_and_no_live_references`.
7. **Regression run.** Run the whole existing suite with all connector modules
   still compiled. Do not disable, ignore, or delete existing tests; rewrite
   only expectations that intentionally exercised the now-removed frontend.
