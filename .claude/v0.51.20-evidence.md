- The active-view workload now commits inserts on the same pgwire session and asserts the exact projected ID result.
- The runtime and CLI now construct the configured S3-compatible object store for MinIO runs while retaining local storage as the default.
- The injected leak is bounded below the test process file limit but remains above the identical gate tolerance.
- Relative artifact paths are normalized to the workspace root so Cargo test execution and the GitHub workflow publish the same TSV/JSON/Markdown location.
- Both sampler scripts are executable, so the plan’s direct shell reproducer works.
