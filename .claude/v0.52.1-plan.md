# v0.52.1 plan — Resumable Online Backfill & Snapshot/Delta Fence

## Scope and non-negotiable invariants

This version makes `CREATE MATERIALIZED VIEW` a durable, streaming lifecycle
instead of `handle_create_view`'s current synchronous full scan.  The only
new public SQL is `SHOW BACKFILL STATUS FOR MATERIALIZED VIEW <name>`; all
roles remain flags on the single `rockstream` binary.

- A fence binds the snapshot to the exact connector position where live work
  resumes.  Every input record is applied once across the boundary, including
  restart at every M3 phase.
- `SNAPSHOTTING -> CATCHING_UP -> RUNNING` is view lifecycle state, not the
  shard-migration state machine.  The view is unreadable until a committed
  cluster frontier proves it caught up.
- A cursor is durable per `(view, source partition)` and contains last key,
  fence position, and committed epoch.  It advances only in the M3 batch that
  persists the corresponding input and output; recovery starts at that cursor.
- Backfill uses `BACKFILL_BATCH_MAX_ROWS`, `BACKFILL_LIVE_DELTA_MAX_BYTES`,
  and `BACKFILL_MAX_PARTITIONS`.  Metrics expose rows, live-delta bytes,
  active partitions, and admission-budget use.  Full buffers reject/pause
  with enumerated errors, never grow in memory.  The new codes are allocated
  centrally: `RS-4019 backfill.cursor_limit_exceeded`, `RS-4020
  backfill.live_delta_buffer_full`, `RS-4021 backfill.admission_rejected`, and
  `RS-4022 backfill.not_published`.
- Cleanup uses bounded prefix scans and point deletes only.  No path uses
  SlateDB range deletion; an explicit source test locks this down.

## Vertical slices

1. **Fence primitive.** Add connector-neutral `SnapshotDeltaFence` beside
   `OffsetToken` in `rockstream-connectors/src/source_epoch.rs`; each adapter
   atomically captures its snapshot plus Kafka offsets, Postgres LSN, or S3
   listing watermark before live polling.  Add the seeded property test
   `snapshot_delta_fence_property_exactly_once_under_restarts` over generated
   records/restarts, asserting the exact multiset equals batch and every ID
   appears once.

2. **Durable cursor/M3 commit.** Add per-view/partition cursor keys and
   bounded scan-and-point-delete cleanup in storage; persist fence, cursor,
   source checkpoint, output and epoch together.  Implement recovery from the
   highest committed cursor only.  Green tests: `backfill_cursor_m3_atomicity_lfs`
   and `backfill_cursor_m3_atomicity_minio`; both assert prepared records do
   not advance recovery and contain an explicit no-range-delete assertion.

3. **Streaming lifecycle coordinator.** Replace the create-time full scan
   with bounded chunks, live-delta interleaving, and `SNAPSHOTTING ->
   CATCHING_UP -> RUNNING`.  Route every chunk through the existing compiled
   pipeline and sink.  Green test:
   `backfill_resume_tests::multi_million_rows_resume_mid_snapshot_mid_interleave_mid_catch_up_exact_oracle`,
   which asserts exact output and no already-committed partition is rescanned.

4. **Publication gate and separate budget.** Extend `CatalogView` and the
   reader path to gate pre-frontier reads; add a separate reservation to the
   existing admission controller, with metrics and `RS-4019..RS-4022` errors.
   Green tests: `backfill_publication_gate_blocks_partial_relation`,
   `backfill_budget_rejects_without_degrading_running_view`, and TC
   `backfill_preserves_running_view_freshness_slo_multi_worker`.

5. **Status through real pgwire.** Add `SHOW BACKFILL STATUS FOR MATERIALIZED
   VIEW <name>` through parser, dispatcher, catalog executor, and existing
   pgwire encoder.  Green tests: `show_backfill_status_pgwire_reachable` and
   `show_backfill_status_reports_exact_phase_cursor_remaining_and_estimate`.

6. **Matrix and fault completion.** Add every named aggregate/join/window
   cell above, LFS/MinIO durability pairs, the fence property test, and seeded
   `backfill_fence_simruntime_restarts_preserve_exactly_once` with `buggify!()`
   at snapshot capture, M3 prepare/commit, interleave drain, and publish.
   End with the complete raw-pgwire lifecycle transcript.
