## New RS-XXXX Codes

No new `RS-XXXX` codes are required. The existing error codes are sufficient:
- `RS-1015` — Group-commit queue full (back-pressure applied)
- `RS-3010` — Durable shuffle buffer capacity exceeded

---

## Architecture Notes

**Lightweight TCP Metrics Server**:
- A background TCP listener will parse basic HTTP GET `/metrics` requests and return Prometheus format metrics directly.
- Avoids external dependencies while ensuring 100% compliance with SRE metric definitions.

**Rate Limiting Wrapper (RetryingObjectStore)**:
- We will implement backoff-and-retry logic inside the durable shuffle path to transparently absorb HTTP 429 / rate limit errors.
- Rate-limiting simulation inside `SimRuntime` will allow testing this backoff loop deterministically.

## Vertical Slices

Each slice ends in a green test gate. Slices are listed in dependency order.

### S1 — Metrics Server and CLI Integration
**Files:**
- [NEW] `crates/rockstream-cli/src/metrics_server.rs`
- `crates/rockstream-cli/src/lib.rs`
- `crates/rockstream-cli/src/main.rs`
- `crates/rockstream-types/src/metrics.rs`

**What:**
- Add process-global flush latency metrics (`FLUSH_DURATION_SECONDS`, `FLUSH_COUNT_TOTAL`).
- Expose a simple TCP-based background HTTP responder for GET `/metrics` displaying Prometheus version 0.0.4 metrics.
- Wire `--metrics-addr` to `rockstream start` and start the metrics server.

**Test gate:** `test_metrics_server_exposition` — verify the server responds to HTTP requests with the correct metrics.

### S2 — Throttled Object Store in SimRuntime
**Files:**
- `crates/rockstream-sim/src/object_store.rs`
- `crates/rockstream-sim/src/sim.rs`

**What:**
- Implement rate limiting (requests/time unit threshold) in `SimObjectStore`.
- Inject HTTP 429 "Too Many Requests" errors when thresholds are exceeded.

**Test gate:** `test_throttled_object_store` — verify HTTP 429 is returned under high frequency operations.

### S3 — Backoff/Retry policy in Coalesced Durable Fallback
**Files:**
- `crates/rockstream-runtime/src/exchange/durable.rs`

**What:**
- Implement exponential backoff and retry loop for object store operations in `DurableShuffleWriter` and `DurableShuffleReader`.
- Add `buggify!()` error injection.

**Test gate:** `test_coalesced_durable_fallback_retry` — verify operations recover and succeed under simulated rate limit faults.

### S4 — 72-Hour Soak test in SimRuntime
**Files:**
- [NEW] `crates/rockstream-runtime/tests/soak_proof_tests.rs`

**What:**
- Heavy simulated workload run for virtual 72 hours using `SimRuntime` time compression.
- Verify group commit & caching successfully minimize object store requests, and retries recover from rate limits.

**Test gate:** `test_object_store_limit_soak_sim`

### S5 — MinIO Rate Limiting integration test
**Files:**
- `crates/rockstream-runtime/tests/soak_proof_tests.rs`

**What:**
- Integration test running MinIO via TestContainers.
- Inject high concurrency to verify retry loop and `/metrics` updates.

**Test gate:** `test_minio_rate_limit_soak_tc`
