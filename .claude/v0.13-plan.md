## 2. Vertical Slices

### Slice 1: Compile-time Cycle Detection & Lowering Integration
- **Goal**: Detect cycles in view-on-view dependencies at view registration and return `RS-1011`. Lower `PlanNode::ViewRef` and `PlanNode::Snapshot` from SQL `TableScan` when referencing registered views or snapshot sources.
- **Changes**:
  - [SqlError](file:///Users/grove/projects/rockstream/crates/rockstream-sql/src/error.rs): Add `CycleDetected` variant mapping to `RS_1011`.
  - [SchemaCatalog](file:///Users/grove/projects/rockstream/crates/rockstream-sql/src/catalog.rs): Add cycle check in `register_view` using `rockstream_plan::dag::detect_cycle`.
  - [lower.rs](file:///Users/grove/projects/rockstream/crates/rockstream-sql/src/lower.rs): Implement `lower_with_views` supporting lowering of registered views to `ViewRef` and snapshot tables to `Snapshot`.
  - [frontend.rs](file:///Users/grove/projects/rockstream/crates/rockstream-sql/src/frontend.rs): Call `lower_with_views` in `create_view` using catalog-defined views.
  - [DiffCtx](file:///Users/grove/projects/rockstream/crates/rockstream-diff/src/lib.rs): Map `PlanNode::Snapshot` and `PlanNode::ViewRef` to their physical counterparts in `diff_node`.
- **Test**: `test_cycle_rejection` in `rockstream-sql/tests/lfs_catalog.rs`.

### Slice 2: Physical Snapshot Operator (SnapshotOp)
- **Goal**: Implement `SnapshotOp` to scan existing table/view outputs in `ShardDb` and emit them in chunked bootstrap epochs.
- **Changes**:
  - New File [snapshot.rs](file:///Users/grove/projects/rockstream/crates/rockstream-ops/src/snapshot.rs): Implement `SnapshotOp`:
    - Scans `ShardPrefix::ViewOutput` for a source ID.
    - Decodes row bytes as big-endian i64.
    - Tracks emitted rows, supporting `resume_from(N)` offset.
    - Enforces named buffer limit `SNAPSHOT_BUFFER_LIMIT = 1_000_000` rows.
- **Test**: Pre-committed oracle property test `oracle_snapshot_matches_batch` and LFS/MinIO durability tests.

### Slice 3: Physical ViewRef Operator (ViewRefOp)
- **Goal**: Implement `ViewRefOp` to tail an upstream view's CDC delta epoch updates.
- **Changes**:
  - New File [view_ref.rs](file:///Users/grove/projects/rockstream/crates/rockstream-ops/src/view_ref.rs): Implement `ViewRefOp` scanning epoch prefix in `view_output` (acting as the conceptual `WalReader`).
- **Test**: Pre-committed oracle property test `oracle_view_ref_matches_batch` and integration tests.

### Slice 4: Resilience and Multi-Level topologies
- **Goal**: Verify restart resilience mid-bootstrap and multi-level view topologies (5-level chain, diamond topology).
- **Test**: E2E integration tests in LFS and MinIO backends.

## 3. Test Commitments & Proof Mapping

### Oracle Property Tests
- `oracle_snapshot_matches_batch` in `snapshot.rs`: Asserts that `SnapshotOp` output equals batch query reference.
- `oracle_view_ref_matches_batch` in `view_ref.rs`: Asserts that `ViewRefOp` tail output matches batch CDC reference.

### Durability Tests (LFS + MinIO)
- `lfs_snapshot_bootstrap_large_scale` & `minio_snapshot_bootstrap_large_scale`: Verify bootstrapping a large-scale (100M-row-equivalent simulated size) dataset.
- `lfs_snapshot_bootstrap_restart_resilience` & `minio_snapshot_bootstrap_restart_resilience`: Verify that interrupting bootstrap and invoking `resume_from` does not duplicate or skip rows.

### Topology/DAG Tests
- `test_5_level_view_chain_convergence`: Checks convergence across a 5-level ViewRef chain.
- `test_diamond_topology_convergence`: Asserts structural diamond consistency under continuous inputs (no group API required).
- `test_cycle_rejection`: Asserts cycle creation fails with `RS-1011`.
