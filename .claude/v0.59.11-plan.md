# v0.59.11 Plan — SQL Ergonomics & Common Expression Completeness

## Scope and Boundary

v0.59.11 implements the SQL Ergonomics and Common Expression Completeness milestone of the Pre-v1 Product Polish track (`NEW_ROADMAP.md` v0.59.11):

1. **Hardened `UPDATE ... RETURNING` (`SQL-01`)**:
   - Harden `UPDATE ... RETURNING` execution across both PostgreSQL simple query and extended query protocols (Parse, Bind, Describe, Execute), including parameterized queries and server-side prepared statements.
   - Support arbitrary projection lists (single column, multiple columns, expression projections, aliased columns, and `*`).
   - Support zero-row matches (empty result set with matching column schema, `UPDATE 0`), single-row updates, and multi-row updates.
   - Maintain transaction-safe post-image capture and read-back guarantees within explicit `BEGIN ... COMMIT` blocks and auto-commit transactions.

2. **Hardened `DELETE ... RETURNING` (`SQL-02`)**:
   - Harden `DELETE ... RETURNING` execution across both PostgreSQL simple query and extended query protocols (Parse, Bind, Describe, Execute), parameterized queries, and prepared statements.
   - Support arbitrary projection lists (single column, multiple columns, expression projections, aliased columns, and `*`).
   - Guarantee pre-image capture across zero-row matches (empty result set, `DELETE 0`), single-row deletions, and multi-row deletions.
   - Ensure transaction-safe pre-image capture within explicit `BEGIN ... COMMIT` and auto-commit transactions without state corruption or phantom tuples.

3. **Consistent `IF EXISTS` & `IF NOT EXISTS` Handling across DDL Object Families (`SQL-03`)**:
   - Provide consistent, idempotent `IF EXISTS` and `IF NOT EXISTS` semantics across all admitted RockStream DDL object families:
     - `TABLE`: `CREATE TABLE [IF NOT EXISTS]`, `DROP TABLE [IF EXISTS]`
     - `VIEW`: `CREATE [OR REPLACE] VIEW [IF NOT EXISTS]`, `DROP VIEW [IF EXISTS]`
     - `MATERIALIZED VIEW`: `CREATE [OR REPLACE] MATERIALIZED VIEW [IF NOT EXISTS]`, `DROP MATERIALIZED VIEW [IF EXISTS]`
     - `INDEX`: `CREATE INDEX [IF NOT EXISTS]`, `DROP INDEX [IF EXISTS]`
     - `WORKLOAD`: `CREATE WORKLOAD [IF NOT EXISTS]`, `DROP WORKLOAD [IF EXISTS]`
     - `SECRET`: `CREATE SECRET [IF NOT EXISTS]`, `DROP SECRET [IF EXISTS]`
     - `SOURCE`: `CREATE SOURCE [IF NOT EXISTS]`, `DROP SOURCE [IF EXISTS]`
     - `SINK`: `CREATE SINK [IF NOT EXISTS]`, `DROP SINK [IF EXISTS]`
     - `SCHEMA`: `CREATE SCHEMA [IF NOT EXISTS]`, `DROP SCHEMA [IF EXISTS]`
   - Ensure `IF NOT EXISTS` is a clean no-op on already existing objects, and `IF EXISTS` is a clean no-op on absent objects without error.
   - Ensure standard non-conditional DDL fails with deterministic error codes (`RS-4001` for already existing objects, `RS-4004` for missing objects).

4. **Typed, Null-Preserving Common Scalar Functions (`SQL-04`)**:
   - Implement typed, null-preserving common scalar functions across three fundamental categories:
     - **String functions**: `UPPER(str)`, `LOWER(str)`, `LENGTH(str)` / `CHAR_LENGTH(str)` / `CHARACTER_LENGTH(str)`, `SUBSTRING(str FROM pos [FOR len])` / `SUBSTR(str, pos [, len])`, `TRIM(str)` / `LTRIM(str)` / `RTRIM(str)`, `CONCAT(str1, str2, ...)`, `CONCAT_WS(sep, str1, str2, ...)`, `REPLACE(str, from, to)`, `SPLIT_PART(str, delim, idx)`, `LPAD(str, len [, pad])`, `RPAD(str, len [, pad])`, `POSITION(substr IN str)` / `STRPOS(str, substr)`.
     - **Null-handling and conditional functions**: `COALESCE(val1, val2, ...)`, `NULLIF(val1, val2)`, Searched `CASE WHEN cond THEN res ... ELSE default END`.
     - **Date/Time functions**: `DATE_TRUNC(unit, ts)`, `EXTRACT(field FROM ts)` / `DATE_PART(field, ts)`, `AGE(ts1 [, ts2])`, `TO_CHAR(ts, format)`, `NOW()`, `CURRENT_TIMESTAMP`, `CURRENT_DATE`, and interval arithmetic (`ts + INTERVAL '1 day'`).
   - Enforce standard SQL three-valued logic and strict NULL propagation (e.g. `UPPER(NULL) -> NULL`, `CONCAT_WS` skipping nulls, `COALESCE` first non-null).
   - Guarantee exact parity between streaming incremental maintenance (IVM `PlanNode` / `Expr` / `eval_to_array`) and batch PostgreSQL oracle execution.

### Non-Negotiable Ground Rules
- Prefix every shell command with `rtk` (e.g. `rtk cargo test`, `rtk git status`).
- One binary, one CLI, one config: every role is a flag on the same `rockstream` binary. `main` remains runnable.
- No code path may depend on SlateDB range deletion. Cleanup is scan-and-delete or snapshot-safe compaction filters.
- Unbounded in-memory accumulation is never acceptable. Every queue, buffer, or scan window has a named upper bound, fill-level metric, and backpressure/error path.
- Do not weaken, skip (`#[ignore]`), or delete tests to make a build pass. Do not use `--no-verify`. Fix the root cause.
- **Nothing may be deferred to a later version.**
- **Pick up all prior deferrals** overlapping this scope.

## 6. Durability and Coordination Commitments

1. **Durability (LFS & MinIO)**:
   - DDL state modified through `IF [NOT] EXISTS` operations (`TABLE`, `VIEW`, `INDEX`, `WORKLOAD`, `SECRET`, `SOURCE`, `SINK`) persists across cluster restarts on both local filesystem SlateDB and MinIO object storage.

   - `v05911_sql_ergonomics_sim_tests::test_dml_returning_under_simulated_faults` executes under `SimRuntime` with seeded RNG and `buggify!()` annotations on:
     - `buggify!("v05911.gateway.returning_read_back_delay")`: Delaying read-back of post-update/pre-delete images during high write concurrency.
     - `buggify!("v05911.gateway.concurrent_ddl_if_exists")`: Concurrent conflicting `CREATE IF NOT EXISTS` / `DROP IF EXISTS` statements.
     - `buggify!("v05911.ops.scalar_eval_error")`: Evaluation of edge-case scalar inputs (out-of-bounds substrings, invalid timestamps).
   - Asserts zero torn writes, zero panic crashes, and strictly monotonic transaction frontiers.
