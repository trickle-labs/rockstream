# v0.59.15 Plan — Current, Simple, Executable Documentation

## Scope and Boundary

v0.59.15 makes the documented product surface current, short, navigable by
persona, generated where a machine-readable source already exists, and
executable where a user must run commands. It consumes v0.59.13's
`ProductSurfaceManifest` and v0.59.14's golden path. It does not add SQL,
wire-protocol, storage, or runtime behavior.

The proof obligations are:

1. The README and getting-started path execute the v0.59.14 demo and local
   scaffold golden path with exact checked-in transcripts.
2. Generated CLI, configuration, function/SQL, catalog, metric, and error
   references exactly reflect `docs/product-surface.json`.
3. Existing public Markdown links remain valid after navigation and history
   are separated.
4. Compatible and incompatible schema-evolution cookbooks run against the
   existing LFS and PostgreSQL-CDC behavior, including exact `RS-1002` output.
5. Every current documentation claim is either generated from a canonical
   source or proved by a named executable test; terminology and contributor
   commands are checked.
6. Contributor and maintainer checks document the existing test taxonomy,
   dependency policy, and compile-time checks as executable commands.

No dependency is added. The existing Rust doc generator, shell-check pattern,
and Python standard library are sufficient.

## 4. Vertical Slices

1. **Persona index and stable navigation (`DOC-002`).** Add the concise README
   path, `docs/README.md`, getting-started, operator, contributor, history, and
   ADR indexes. Preserve current public paths as compatibility pages. Green:
   navigation/link tests cover the complete expected destination set.
2. **Manifest-backed Markdown references (`DOC-004`).** Extend the existing
   `rockstream-docgen` command with deterministic Markdown rendering; generate
   the six reference surfaces and retain `docs/product-surface.json` as the
   input artifact. Green: renderer output equals every checked-in reference
   byte-for-byte and product-surface drift remains zero.
3. **Executable golden-path and schema cookbooks (`DOC-003`).** Publish only
   commands already exercised by v0.59.14 and schema-evolution tests; capture
   exact outputs, layouts, and `RS-1002` failure behavior. Green: LFS and
   PostgreSQL-CDC cookbook paths produce their complete expected artifacts.
4. **Documentation admission gate and maintainer material.** Add the standard
   test taxonomy, focused contributor guides, minimal ADRs for generated
   references, transcript ownership, and link compatibility, plus the
   historical-plan archive index. Green: checker and mutation self-test reject
   a broken link, stale generated file, unsupported claim, obsolete term, and
   nonexistent command with exact diagnostics.

format, or simulation commitment is introduced.
