## Vertical Slices

### S1 — Define SQL DDL constants and implement `NexmarkGenerator`

**What:**
- Implement `NexmarkGenerator` and `NexmarkEvent` in `crates/rockstream-sim/src/nexmark.rs`.
- `NexmarkEvent` will support formatting fields for `person`, `auction`, and `bid` as standard SQL `INSERT` statements.
- `NexmarkGenerator` will be initialized with a `u64` seed, use `StdRng` for deterministic generation, and maintain correct Nexmark distribution: 1 Person : 3 Auctions : 46 Bids (2% Persons, 6% Auctions, 92% Bids).
- Maintain internal ID pools to ensure generated bids and auctions refer to valid bidder/seller/auction IDs.
- Export modules in `crates/rockstream-sim/src/lib.rs`.

**Exit test (green):**
- Unit test `test_nexmark_generator_determinism` — verifies that generating 1000 events twice from the same seed produces identical events.
- Unit test `test_nexmark_generator_distribution` — verifies that generating 10,000 events produces a distribution within 1% of the target ratios (92% Bids, 6% Auctions, 2% Persons).

---

### S2 — Test Scaffold & DDL Catalog Round-trip (LFS)

**What:**
- Create `crates/rockstream-sql/tests/nexmark/main.rs` and write a test case to bring up an in-process `GatewayServer` using a local filesystem `ShardDb`.
- Define the DDL SQL string constants for creating the `person`, `auction`, and `bid` base tables.
- Execute `CREATE TABLE` commands for all three schemas over pgwire via `tokio-postgres`.

**Exit test (green):**
- Integration test `test_nexmark_schema_creation_and_catalog` — connects to the gateway, runs the `CREATE TABLE` statements, and asserts that the tables are registered and queryable in `information_schema.tables` and `pg_catalog.pg_tables`.

---

### S3 — Ingest events via pgwire and verify SELECT counts (LFS)

**What:**
- Extend the test scaffold to generate a batch of events (e.g., 500 events) using `NexmarkGenerator`.
- Ingest them by executing the generated `INSERT` statements via `tokio-postgres`.
- Every batch write will execute within a transaction (`BEGIN` / `COMMIT`) and set a session-level `idempotency_key` via `SET rockstream.idempotency_key = '<key>'`.
- Verify the row counts in `person`, `auction`, and `bid` match the generator counts.

**Exit test (green):**
- Integration test `test_nexmark_ingestion_lfs` — generates events, inserts them via pgwire, and asserts that `SELECT COUNT(*)` on each of the three tables returns the exact count of generated events.

---

### S4 — MinIO (S3 via TestContainers) Integration

**What:**
- Add a TestContainers MinIO-backed integration test for the end-to-end ingestion flow.
- Fall back gracefully (ignoring or skipping the test) if Docker is unavailable.

**Exit test (green):**
- Integration test `test_nexmark_ingestion_minio` — runs the end-to-end ingestion flow against a MinIO-backed gateway instance and verifies exact row counts.
