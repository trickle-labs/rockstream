# v0.51.26 Implementation Plan — Leak-Free Long-Lived Registries & Identity-Safe Caps

**Version**: v0.51.26  
**Phase**: Phase 2 — Plan  
**Target Scope**: Close finding (6) — the concrete defects v0.51.20's soak gate is designed to catch, fixed so that gate can be green rather than merely honest. ## 4. Vertical Slices

- **Slice S1: FlowController Exchange Teardown & Metrics**
  - *Goal*: Implement `teardown_exchange(exchange_id: u64)` in `flow_control.rs` to purge channel credits and notifier entries when an exchange is destroyed. Update metrics.
  - *Verification*: `registry_lifecycle_tests.rs::test_exchange_teardown_clears_flow_control_maps`.

- **Slice S2: Multiplexer & Pool Worker Death Eviction**
  - *Goal*: Add `evict_worker(worker_id: WorkerId)` to `multiplexer.rs` and `pool.rs` to drop streams and cached gRPC/SHM clients on worker death or drain. Update metrics.
  - *Verification*: `registry_lifecycle_tests.rs::test_worker_eviction_clears_multiplexer_streams_and_pool`.

- **Slice S3: Webhook Source Pending Delivery TTL Eviction**
  - *Goal*: Add timestamp tracking and `pending_ttl` sweep to `HttpWebhookSource` in `webhook_source.rs` so unacknowledged delivery identities do not persist indefinitely.
  - *Verification*: `registry_lifecycle_tests.rs::test_webhook_unacknowledged_delivery_ttl_eviction`.

- **Slice S4: mTLS Capacity Cap Rejection (`RS-2406`) & Disconnect Cleanup**
  - *Goal*: Modify `tls.rs` so handshakes past `MAX_CONNECTIONS` are rejected with documented error `RS-2406` (never silently authenticated without CN). Ensure abnormal TCP drops remove entries from `MTLS_CN_BY_PEER_ADDR`.
  - *Verification*: `registry_lifecycle_tests.rs::test_mtls_cn_map_cap_rejection_and_disconnect_cleanup`.

- **Slice S5: Comprehensive Registry Lifecycle Integration Suite**
  - *Goal*: Build `registry_lifecycle_tests.rs` asserting that after 50,000 exchange teardowns, 10,000 worker registrations, and 100,000 unacknowledged webhook deliveries, all registry fill-level gauges return to their baseline.
  - *Verification*: `registry_lifecycle_tests.rs::test_full_registry_lifecycle_gauge_baseline`.

- **Slice S6: Real-Binary Soak Gate Validation (v0.51.20)**
  - *Goal*: Run `resource_leak_soak_real_binary_tests` against the real binary and confirm flat RSS, flat FD count, and flat socket count across the full window.
  - *Verification*: `resource_leak_soak_real_binary_tests.rs`.
