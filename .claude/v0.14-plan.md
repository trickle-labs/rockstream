### Slice 2: TPC-H 22/22 Incremental vs. Batch Equivalence & Performance Test Suite
- **Goal**: Implement all 22 TPC-H SQL queries, lower them via `SqlFrontend`, run them incrementally on the IVM engine, and verify the output matches DataFusion batch query results.
- **Changes**:
  - New File [tpch_soak_e2e.rs](file:///Users/grove/projects/rockstream/crates/rockstream-sql/tests/tpch_soak_e2e.rs):
    - Defines all 22 TPC-H query strings.
    - Lowers and executes them incrementally: Epoch 0 bootstrap snapshot, Epoch 1..N delta batches.
    - Compares accumulated Z-set output against DataFusion batch query execution at each epoch boundary.
    - Verifies execution speeds to prove >=10x speedup vs. batch at a 1% change rate.
- **Test**: `test_tpch_queries_incremental_vs_batch` on LFS and MinIO backends.

- **Changes**:
