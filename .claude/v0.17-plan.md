## 2. Vertical Slices

### Slice 1: Rendezvous Hashing with Virtual Nodes
- **Goal**: Implement deterministic Highest Random Weight (Rendezvous) hashing mapping virtual buckets to physical shards.
- **Changes**:
  - [NEW] [rendezvous.rs](file:///Users/grove/projects/rockstream/crates/rockstream-types/src/rendezvous.rs): Implement FNV-1a 64-bit deterministic hash and `rendezvous_hash` mapping buckets to `ShardId` using virtual nodes.
  - [MODIFY] [lib.rs](file:///Users/grove/projects/rockstream/crates/rockstream-types/src/lib.rs): Register and export the `rendezvous` module.
- **Test**: Run `rtk cargo test -p rockstream-types --lib rendezvous` to verify uniform distribution and re-balance minimality (only $\approx 1/W$ keys migrate when a new shard is added, and no keys migrate between existing shards).

### Slice 2: Coalesced Durable Shuffle Writer & Reader
- **Goal**: Implement object-store fallback reader/writer utilizing coalesced shuffle objects with an index footer to avoid listing operations on the hot path in S3/MinIO.
- **Changes**:
  - [NEW] [durable.rs](file:///Users/grove/projects/rockstream/crates/rockstream-runtime/src/exchange/durable.rs): Implement `DurableShuffleWriter` and `DurableShuffleReader`.
    - `DurableShuffleWriter` concatenates frame bytes, builds `ShuffleIndexFooter` mapping `(src_shard, target_shard, seq, offset, length)`, appends the serialized footer and footer length, and writes to `shuffle/{exchange_id}/{epoch}/{src_worker}/{target_worker}.arrow` in the object store.
    - `DurableShuffleReader` performs range reads of the last 8 bytes to get the footer length, retrieves the index footer, and pulls only the target shards' frames via range reads.
  - [MODIFY] [mod.rs](file:///Users/grove/projects/rockstream/crates/rockstream-runtime/src/exchange/mod.rs): Export the `durable` module.
- **Test**: Unit tests asserting file construction, footer deserialization, and precise range-read frame extraction.

### Slice 3: Durable Shuffle Fallback Integration
- **Goal**: Integrate the fallback writer/reader into the worker multiplexer.
- **Changes**:
  - [MODIFY] [multiplexer.rs](file:///Users/grove/projects/rockstream/crates/rockstream-runtime/src/exchange/multiplexer.rs): Fall back to the durable path (`ExchangePath::Durable`) if direct gRPC stream fails or the receiver is unreachable.
- **Test**: Integration test `test_durable_shuffle_fallback` using MinIO TestContainers. Injects receiver failure, verifies the sender falls back to object store, recovers the receiver, and catches up via object store with no duplicates or LIST operations.

### Slice 4: Distributed Parity Validation
- **Goal**: Re-run the Phase 1–3 oracle property tests and TPC-H suite on the distributed multi-worker cluster using the rendezvous router.
- **Changes**:
  - [MODIFY] [exchange_integration.rs](file:///Users/grove/projects/rockstream/crates/rockstream-runtime/tests/exchange_integration.rs): Run oracle fuzz cases and TPC-H queries on the distributed cluster.
- **Test**: Verify that distributed cluster results are bit-identical to single-shard runs.
