# v0.52.4 plan — Connector Surface Reduction

## 1. Deferred-item audit

### Must implement this version

None. A complete scan of `sign-offs/v*.md` found no deferred, postponed, or
out-of-scope item that overlaps this deletion scope. In particular,
`v0.52.1`, `v0.52.2`, and `v0.52.3` explicitly defer nothing; v0.52.3
announced this implementation/dependency/M5 retirement for v0.52.4.

The only earlier deferrals are already-completed or separately scheduled IVM,
recovery, and exchange work (v0.1–v0.6), plus v0.51.3 view refresh completed
in v0.51.4. They do not overlap connector deletion. No undocumented
in-scope deferral was found.

### Out of scope — flag for follow-up version

* Connector admission policy belongs to v0.52.5; it is not required to remove
  the cold-tier family and must not be pulled forward.
* Retained Kafka, Postgres CDC, and `FaultInjectingObjectStore` behavior is
  regression-only work this version, not a redesign.

Nothing is deferred from v0.52.4.

## 4. Vertical slices

1. **Freeze the compatible rejection boundary.** Keep the raw pgwire
   `is_removed_connector_ddl` branch and catalog normalization; replace the
   webhook enum-dependent response with a server-local fixed response. Green:
   every Removed wire-surface matrix cell, including LFS and MinIO, is green.
2. **Delete connector implementations and dead abstractions.** Remove
   `s3_source.rs`, `object_store_sink.rs`, `iceberg_sink.rs`, `delta_sink.rs`,
   `cold_tier_sink.rs`, `cold_gc.rs`, `partition_spec.rs`, and
   `catalog_registrar.rs`; reduce `lib.rs` to exactly the retained modules and
   exports. Delete the M5-only `assert_commit_pointer_atomic` and documentation
   from `sink_connector.rs`, while retaining the Kafka 2PC contract. Green:
   the exact connector surface contract and retained Kafka/CDC tests compile.
3. **Delete gateway source runtime wiring.** Remove `webhook_source.rs`, its
   `lib.rs` export, registry fields/init, lifecycle/ingest hooks, and all S3
   builder/backfill/worker branches in `server.rs`. Delete only tests whose
   sole subject is removed behavior; split mixed tests rather than removing
   retained Kafka/CDC or generic fault coverage. Green: the prohibited-symbol
   contract and fail-closed wire matrix are green.
4. **Prune only dead dependencies.** Remove connector-only `iceberg`,
   `deltalake`, `aws-sdk-s3`, `aws-config`, `csv`, and `parquet` declarations;
   refresh `Cargo.lock`. Keep `object_store` because
   `FaultInjectingObjectStore` is retained. Green: all dependency matrix
   commands prove the effective graph rather than relying on manifest review.
5. **Retire M5.** Move `formal/m5_cold_tier_sink.fizz` and its generated JSON
   record to `formal/retired/`, adding the retirement header; remove M5 from
   `Makefile`, CI, formal README, invariant-pair expectations, and the active
   FizzBee mapping. Keep an explicit historical retirement note rather than a
   live gate. Green: active formal commands run M1–M4/M6/M7 and the paired
   script's exact fixture proves M5 is retired.
6. **Remove live documentation and test-only remnants.** Delete
   `docs/cold-tier-sinks.md`, redirect `docs/connector-migration.md` to the
   removed-surface replacements, and remove active M5/connector references
   from docs and code comments (including `rockstream-sim` and control test
   comments). Green: the complete allowed-reference scan is exact.
7. **Measure and regress.** Record before/after `cargo metadata` dependency
   count, release-build wall time, and CI wall time in the sign-off. Run the
   retained exactly-once, recovery, chaos, Nexmark, and pgwire conformance
   suites on LFS, MinIO, and TestContainers, with no new `#[ignore]`, disabled,
   or weakened test.
