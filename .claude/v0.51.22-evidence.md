# v0.51.22 Phase 4 Evidence

Status: complete for the redesigned workspace-coverage gate.

## Gate selected

The coverage gate collects one complete explicit feature-matrix report, then
runs report-only per-crate floors against that same report:

```text
cargo llvm-cov --workspace --lib --tests --no-report
cargo llvm-cov --no-clean -p rockstream-gateway --features testcontainers --test <gated-target> --no-report
cargo llvm-cov --no-clean -p rockstream-sim --features simulation --test <gated-target> --no-report
cargo llvm-cov --no-clean -p rockstream-sim --features docker_tests --test <gated-target> --no-report
cargo llvm-cov report --no-clean --lcov --output-path lcov.info
cargo llvm-cov report --package <crate> --fail-under-lines <floor> --fail-under-regions <floor>
```

The `--lib --tests` scope includes every test-bearing workspace library and
integration-test target while avoiding zero-test binaries/examples and
Criterion argument parsing. Benchmarks remain separate CI gates.
