# v0.59.12 Plan — Error Catalog Foundation & Dispatch Conformance

## Scope and Boundary

v0.59.12 implements the Error Catalog Foundation and Dispatch Conformance milestone of the Pre-v1 Product Polish track (`NEW_ROADMAP.md` v0.59.12):

1. **Authoritative Static `RS-XXXX` Error Catalog (`DOC-01`)**:
   - Establish `contracts/errors.toml` as the single authoritative, machine-readable declaration of all system error codes (`RS-0001` through `RS-5035` and beyond).
   - Each error definition owns 8 canonical fields:
     - `code`: `ErrorCode` (`u16`, formatted `RS-XXXX`).
     - `key`: `&'static str` (unique, lowercase dot-delimited identifier e.g. `"query.timeout"`, `"relation.not_found"`).
     - `title`: `&'static str` (canonical human-readable summary).
     - `severity`: `Severity` (`Info`, `Warning`, `Error`, `Fatal`).
     - `sqlstate`: `&'static str` (5-character standard PostgreSQL SQLSTATE complying with ANSI/PostgreSQL class specifications, e.g. `"42P01"`, `"22003"`, `"XX000"`, `"55000"`, `"08006"`, `"28000"`).
     - `retry_class`: `RetryClass` (`NonRetryable`, `Immediate`, `ExponentialBackoff`, `AfterLeaderElection`, `AfterClusterRecovery`).
     - `default_next_steps`: `&'static str` (clear, actionable operational guidance).
     - `doc_anchor`: `&'static str` (deterministic lowercase slug anchor e.g. `"rs-0001"`).

2. **Rust Constants, Catalog Registry & Generator (`DOC-01`)**:
   - Embed the authoritative catalog directly into `crates/rockstream-types` with type-safe descriptor lookups: `ErrorDescriptor::lookup(code: ErrorCode) -> Option<&'static ErrorDescriptor>` and `ErrorDescriptor::by_key(key: &str) -> Option<&'static ErrorDescriptor>`.
   - Maintain static `RS_XXXX` constant declarations in `crates/rockstream-types/src/error_code.rs` with zero drift against `contracts/errors.toml`.
   - Provide generator tooling `scripts/generate-error-catalog.py` to regenerate or check Rust constant definitions and reference documentation.

3. **Reference Documentation Generation & Drift Gate (`DOC-01`)**:
   - Generated reference documentation `docs/error-codes.md` cataloging all `RS-XXXX` codes grouped by subsystem:
     - `0xxx`: Internal / System Configuration (`RS_0001`–`RS_0005`)
     - `1xxx`: Pipeline, Plan & Optimization (`RS_1001`–`RS_1030`, `RS_1512`–`RS_1513`)
     - `17xx`: Lease Management & Raft Leadership (`RS_1701`–`RS_1731`)
     - `2xxx`: Gateway, Query Execution & Wire Protocol (`RS_2001`–`RS_2030`)
     - `24xx`: Authentication, mTLS & Secrets (`RS_2400`–`RS_2426`)
     - `3xxx`: Storage, Execution, Memory & Shuffle (`RS_3009`–`RS_3708`)
     - `4xxx`: DDL, Catalog, Ingestion & Removed Connectors (`RS_4001`–`RS_4020`)
     - `5xxx`: Cluster, Node Lifecycle & Shard Coordination (`RS_5001`–`RS_5035`)
   - Drift gate CI checks (`scripts/check-error-catalog.sh` / `scripts/check-error-catalog.py` and `scripts/check-error-codes.sh`) ensuring catalog metadata, Rust constants, and markdown documentation remain 100% synchronized with zero manual drift.

4. **Dispatch Conformance & 4-Stage Pipeline Sweep**:
   - Full sweep of all new SQL, SHOW, and catalog dispatch paths introduced across v0.59.10 (`SHOW CAPABILITIES`, `SELECT rockstream_version()`, `rockstream_catalog.*`), v0.59.11 (`UPDATE/DELETE ... RETURNING`, `IF [NOT] EXISTS`, scalar functions), and core engine.
   - Ensure every public error code emitted across pgwire, simple query, extended query, DDL, and DML paths resolves to a registered descriptor with accurate SQLSTATE and actionable next-steps.
   - Audit all 21 statement/command families with 0 `MISSING` paths across Parser -> Dispatcher -> Executor -> Response Encoder.

### Non-Negotiable Ground Rules
- Prefix every shell command with `rtk` (e.g. `rtk cargo test`, `rtk git status`).
- One binary, one CLI, one config: every role is a flag on the same `rockstream` binary. `main` remains runnable.
- No code path may depend on SlateDB range deletion. Cleanup is scan-and-delete or snapshot-safe compaction filters.
- Unbounded in-memory accumulation is never acceptable. Every queue, buffer, or scan window has a named upper bound, fill-level metric, and backpressure/error path.
- Do not weaken, skip (`#[ignore]`), or delete tests to make a build pass. Do not use `--no-verify`. Fix the root cause.
- **Nothing may be deferred to a later version.**
- **Pick up all prior deferrals** overlapping this scope.
