## 2. Reachability & E2E pgwire Evidence (SQL / Wire Protocol)

### 2.1 pgwire Protocol Error Response Envelopes
- **Test File**: `crates/rockstream-gateway/tests/error_catalog_e2e_tests.rs`
- **Function**: `test_pgwire_error_response_envelope`
- **Wire Verification**: Connects a real `tokio-postgres` client over TCP to `GatewayServer`, triggers errors across simple queries (non-existent table/view), and DDL parse errors (`CREATE SINK` syntax). Validates that:
  - Error response envelope returns Postgres DB error.
  - `severity()` is `"ERROR"`.
  - `code()` returns standard SQLSTATE (`42P01` for absent relation, `42601` for syntax error).
  - Error messages contain human-readable text and descriptor lookups match the authoritative catalog.

### 2.2 Error Dispatch Conformance Suite
- **Test File**: `crates/rockstream-gateway/tests/error_dispatch_conformance_tests.rs`
- **Functions**:
  - `test_absent_view_error_dispatch`: Querying non-existent view (`SELECT * FROM non_existent_view_42`) fails with SQLSTATE `42P01` and resolves to descriptor `RS-2001` (`"relation.not_found"`).
  - `test_duplicate_table_error_dispatch`: Creating duplicate table without `IF NOT EXISTS` (`CREATE TABLE existing_t (id INT)`) returns SQLSTATE `42710` and resolves to descriptor `RS-4001` (`"table.already_exists"`).
  - `test_malformed_returning_error_dispatch`: Invalid returning projection returns SQLSTATE `42601` and resolves to descriptor `RS-2022` (`"query.invalid_returning"`).
  - `test_arithmetic_overflow_error_dispatch`: Arithmetic overflow resolves to descriptor `RS_1016` (`"eval.overflow"`) with SQLSTATE `22003`.
  - `test_mtls_missing_cert_error_dispatch`: Unauthenticated / missing mTLS client cert resolves to descriptor `RS_2404` (`"auth.mtls_no_verified_cert"`) with SQLSTATE `28000`.
  - `test_secret_in_use_error_dispatch`: Dropping active secret in use by a source resolves to descriptor `RS_2426` (`"secret.in_use"`) with SQLSTATE `55000`.
  - `test_removed_connector_error_dispatch`: Creating a removed legacy connector source resolves to descriptor `RS_4017` (`"ddl.connector_removed"`) with SQLSTATE `0A000`.
