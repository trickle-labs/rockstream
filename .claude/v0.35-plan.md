## Vertical Slices

### S1 — Implement Q12 & Q13 Queries (LFS)

**What:**
- Define standard `CREATE TABLE side_input` and populate it with static lookup data for stream enrichment.
- Define standard `CREATE VIEW` statements for queries:
  - `q12` (processing-time tumbling window using deterministic `date_bin` and `cast(date_time as timestamp)`)
  - `q13` (bounded side-input join by joining `bid` with `side_input` table)
- In `crates/rockstream-sql/tests/nexmark/main.rs`, implement integration test `test_nexmark_q12_q13_lfs`.
- Bring up `GatewayServer` using LFS-backed `ShardDb`, run DDL and event insertions, and verify results against DataFusion batch oracle.

**Exit test (green):**
- Integration test `test_nexmark_q12_q13_lfs` — registers views, inserts events, and asserts results against DataFusion batch oracle.
