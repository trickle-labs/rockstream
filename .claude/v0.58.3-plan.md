# v0.58.3 Plan — Unscoped Reachability, Dispatch-Wiring & Silent-Wrong-Answer Sweep

## Scope and Boundary

v0.58.3 performs the comprehensive, unscoped reachability, dispatch-wiring, and silent-wrong-answer sweep across the entire RockStream engine per `ROCKSTREAM_PROJECT_FOCUS.md` §10 Stage 5 and `NEW_ROADMAP.md` v0.58.3.

Per the 2026-08-12 realism review split:
- **v0.58**: Failure matrix enumeration and deterministic `SimRuntime` coverage across all 11 production failure modes.
- **v0.58.1**: Real-backend failure proofs, per-cell time budgets, and published recovery baselines.
- **v0.58.2**: Storage-pressure admission signals, shedding order, and SLO auto-tuning lock.
- **v0.58.3 (this version)**:
  1. **Unscoped Reachability Audit & E2E Pgwire Suite**:
     - Every SQL keyword, DDL statement, and `SHOW` command documented as implemented in `docs/language-features.md` across v0.1–v0.58.2 must have a passing end-to-end pgwire reachability test (raw SQL executed through the real gateway dispatcher, not private unit tests).
     - Close the "code exists in a crate but is never wired to pgwire dispatch" gap class once and for all.
  2. **Unscoped Dispatch-Wiring Audit**:
     - Verify complete 4-stage pipeline wiring (Parser → Dispatcher → Executor → Response Encoder) across the entire documented SQL surface.
     - Report zero `MISSING` links anywhere in the documented surface.
  3. **Unscoped Silent-Wrong-Answer Sweep**:
     - Sweep the entire codebase for reachable input-dependent `unreachable!()`, `todo!()`, `unimplemented!()`, silent-zero or default-constant substitutions, and acknowledged-but-discarded error branches.
     - Eliminate all reachable panics and silent-wrong-answer paths in production crates, replacing them with explicit `RS-XXXX` coded errors or exhaustive match handling.
  4. **Repeatable CI Audit Script & Paired Self-Test**:
     - Check in `scripts/check-dispatch-wiring.sh` and its paired `scripts/check-dispatch-wiring.test.sh` self-test.
     - Check in `scripts/check-no-unreachable.sh` and `scripts/check-no-unreachable.test.sh`.
     - Provide the exact verification harness so v0.59 RC1 can re-run the entire sweep as an entry criterion without manual discovery.

### Non-Negotiable Ground Rules
- Prefix every shell command with `rtk` (e.g. `rtk cargo test`, `rtk git status`).
- One binary, one CLI, one config: every role is a flag on the same `rockstream` binary. `main` must remain runnable.
- No code path may depend on SlateDB range deletion. Cleanup is scan-and-delete or snapshot-safe compaction filters.
- Unbounded in-memory accumulation is never acceptable. Every queue, buffer, or scan window needs a named upper bound, fill-level metric, and backpressure or error path.
- Do not weaken, skip (`#[ignore]`), or delete tests.
- **Nothing may be deferred to a later version.**
- **Pick up all prior deferrals** overlapping this scope.

## 2. Unscoped Dispatch-Wiring Audit

Every SQL keyword, DDL statement, and `SHOW` command documented as implemented in `docs/language-features.md` must traverse a complete 4-stage pipeline:
1. **Parser**: SQL parsing and statement recognition (`rockstream-sql` or `rockstream-gateway`).
2. **Dispatcher**: Routing to appropriate handler (`rockstream-gateway::server`).
3. **Executor**: Execution logic in engine, catalog, or operator layer (`rockstream-ops`, `rockstream-control`, `rockstream-gateway::catalog_stubs`).
4. **Response Encoder**: Protocol wire encoding into pgwire responses (`rockstream-gateway::server::DataRowEncoder`).
