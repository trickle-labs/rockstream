## Vertical Test-First Slices

### S1 — Complete feature-matrix execution

**Owned files:** `.github/workflows/ci.yml`,
`.github/workflows/simulation-soak.yml`, feature-matrix regression test.

Write the regression test first. Change CI's workspace test and coverage
commands to use the complete explicit feature matrix, and enable
`simulation` for both chaos-soak invocations. Record before/after test binary
and test-result counts. The permanent test asserts the exact matrix above;
the temporary failing-assertion proof establishes that a gated file is not
merely discovered but executed.

### S2 — Honest Docker availability

**Owned files:** minimal new shared test-only helper crate/module, its tests,
and the 45 affected integration-test files; Docker-provisioning workflow jobs.

Write helper tests first. Reuse existing `Command::new("docker").args(["info"])`
checking as the probe, centralize the environment policy, and replace every
per-file probe plus `eprintln!("SKIP …"); return;` branch with the helper.
Local runs continue to skip when Docker is absent; `ROCKSTREAM_REQUIRE_DOCKER=1`
turns the same condition into an exact actionable panic. Set that variable in
every CI job that provisions Docker. Do not change the test bodies or weaken
their assertions.

### S3 — Structural CI and conformance proof

**Owned files:** `crates/rockstream-gateway/tests/conformance_doc_tests.rs`,
its `Cargo.toml`/workspace dependency entry only if required for the existing
locked YAML parser, the test-result report producer, and `.github/workflows/ci.yml`.

Write negative tests first: a missing crate floor, a floor below baseline, and
a documented stub must each fail. Replace raw YAML/string parsing with a YAML
document parser and inspect the `coverage` job's actual steps. Produce and
consume an execution-result JSON artifact so a linked name requires a real
test result, not a textual `fn` match. Keep the report bounded to the current
test invocation and fail if it is missing, malformed, or lacks a link.

### S4 — Path-filter completeness and coverage ratchet

**Owned files:** `.github/workflows/ci.yml`,
`.github/workflows/real-cluster-chaos.yml`, conformance workflow tests, and
the committed measured-floor table/evidence.

Write exact filter tests first for each previously omitted crate. Broaden both
filters to all workspace crates. Run the complete-feature coverage collection,
record every crate's lines/regions baseline, and update each floor to
`max(current_floor, floor(measured_baseline))`; no floor may decrease.
