## Implementation Notes

1. **Slice 1** (SQLSTATE): Foundation for all error handling; no external dependencies.
2. **Slice 2** (CancelRequest): Uses tokio `CancellationToken` for efficient query interruption.
3. **Slice 3** (Cursors): HashMap-based cursor registry with 100-cursor-per-connection limit.
4. **Slice 4** (Streaming): Batch iterator with configurable batch size; tested with 1000-row batches.
5. **Slice 5** (PgBouncer): Transaction state machine (`TxStatus::Idle/InTransaction/Failed`) tracked per session.
6. **Slice 6** (pg_stat_activity): Registry-based connection monitoring; reflects query state in real-time.
7. **Slice 7** (Fuzzer): `proptest` with deterministic seed; 200 default cases, scales to 50k+ in CI.
8. **Slice 8** (Stress): 1000 concurrent connections fully exercised; PgBouncer session reuse verified.
