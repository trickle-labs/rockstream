| Buffer / Queue | Upper Bound | Fill Metric | Backpressure / Error |
|----------------|-------------|-------------|----------------------|
| COPY IN row buffer (per connection) | `MAX_COPY_IN_BATCH_ROWS = 10_000 rows` or `COPY_IN_FLUSH_BYTES = 64 MiB` (whichever is reached first) | `COPY_IN_BUFFER_ROWS: AtomicU64` (gauge; decrements on flush) | Auto-flush: commit batch to shard and reset buffer; no RS error from accumulation alone |

## Architecture Notes

**State sharing between `do_query` and `CopyHandler` callbacks:**

`do_query` detects `COPY <table> [(<cols>)] FROM STDIN` and stores a `CopyState`
keyed by `conn_id` (the `"_rs_conn_id"` metadata field) in a new
`copy_states: Arc<DashMap<String, CopyState>>` on `GatewayHandler`.
`on_copy_data` / `on_copy_done` / `on_copy_fail` look up the same `conn_id`
from `client.metadata()["_rs_conn_id"]`.

`GatewayHandler` implements the `CopyHandler` trait directly; the factory
changes `type CopyHandler = NoopCopyHandler` → `type CopyHandler = GatewayHandler`.

**Text-format TSV parsing:**
Standard Postgres `COPY FROM STDIN` (text format): tab-separated fields, one row
per newline, terminated by the sentinel `\.\n`. `CopyData` messages may split
rows across message boundaries; `CopyState::partial_line` accumulates the
incomplete tail until the next message completes the line.

**Auto-flush (memory exhaustion prevention):**
Inside `on_copy_data`, after appending each complete row, check:
```
if state.buf_rows.len() >= MAX_COPY_IN_BATCH_ROWS
   || state.buf_bytes   >= COPY_IN_FLUSH_BYTES
{
    flush_copy_batch(&state, &shard_db, conn_id).await?;
    state.buf_rows.clear();
    state.buf_bytes = 0;
}
```
Each flush increments `state.total_rows_flushed` and allocates a new epoch.

**No range-delete dependency:** flush uses `WriteBatch::put` only (same as
existing `handle_commit`). No scan-and-delete is required for COPY.

### S2 — `CopyState` module + `parse_copy_from_stmt` parser

**Files:**
- `crates/rockstream-gateway/src/copy_state.rs` (new)

**What:**

```rust
/// Named upper bound: auto-flush row count.
pub const MAX_COPY_IN_BATCH_ROWS: usize = 10_000;
/// Named upper bound: auto-flush byte size (64 MiB).
pub const COPY_IN_FLUSH_BYTES: usize = 64 * 1024 * 1024;

/// Fill-level metric: current rows in all active COPY IN buffers.
pub static COPY_IN_BUFFER_ROWS: AtomicU64 = AtomicU64::new(0);

pub struct CopyState {
    pub table: String,
    pub columns: Vec<String>,      // empty = infer from catalog
    pub buf_rows: Vec<DmlOp>,
    pub buf_bytes: usize,
    pub partial_line: String,      // accumulates bytes spanning CopyData messages
    pub total_rows_flushed: usize,
}

/// Parse `COPY <table> [(<col1>, <col2>, ...)] FROM STDIN [WITH (...)]`.
/// Returns `(table_name, columns)` on success.
pub fn parse_copy_from_stmt(q: &str) -> Result<(String, Vec<String>), String>
```

**Test gate:** `parse_copy_from_stmt_variants` — unit tests for:
- `COPY t FROM STDIN` → `("t", [])`
- `COPY t (a, b, c) FROM STDIN` → `("t", ["a","b","c"])`
- `COPY my_table (id, val) FROM STDIN WITH (FORMAT TEXT)` → `("my_table", ["id","val"])`
- Invalid input → `Err(...)`

### S3 — `copy_states` field + `do_query` COPY FROM STDIN detection

**Files:**
- `crates/rockstream-gateway/src/server.rs`

**What:**
1. Add `copy_states: Arc<DashMap<String, CopyState>>` to `GatewayHandler` (initialized in `new`, `with_shard_db`).
2. In `do_query`, after COPY OUT check, add COPY IN detection:
   ```rust
   if ql.starts_with("copy ") && ql.contains(" from stdin") {
       return self.handle_copy_from_stdin(query, &conn_id, client).await;
   }
   ```
3. `handle_copy_from_stdin`:
   - Call `parse_copy_from_stmt(query)` → `(table, columns)` or RS-2500 if table unknown when catalog has it registered.
   - Resolve columns: if empty, look up `catalog.get_table(&table)` for column names; if table not in catalog, accept without column validation (passthrough mode).
   - Auth check: `pipeline_owner` role required; RS-2400/RS-2401 otherwise.
   - Insert `CopyState` into `copy_states[conn_id]`.
   - Return `Response::CopyIn(CopyResponse::new(0, col_count as usize, vec![0; col_count]))`.

**Test gate:** `copy_from_stdin_returns_copy_in_response` — raw pgwire test: send `COPY t FROM STDIN`; assert first message back is a `CopyInResponse` byte (`G` = 0x47) after the startup sequence.

### S4 — `CopyHandler` impl on `GatewayHandler` (text TSV, no auto-flush)

**Files:**
- `crates/rockstream-gateway/src/server.rs` — `impl CopyHandler for GatewayHandler`
- `crates/rockstream-gateway/src/server.rs` — `GatewayHandlerFactory`: change `type CopyHandler = GatewayHandler`

**What:**

```rust
#[async_trait]
impl CopyHandler for GatewayHandler {
    async fn on_copy_data<C>(&self, client: &mut C, copy_data: CopyData) -> PgWireResult<()>
    // ...
    async fn on_copy_done<C>(&self, client: &mut C, _done: CopyDone) -> PgWireResult<()>
    // ...
    async fn on_copy_fail<C>(&self, client: &mut C, fail: CopyFail) -> PgWireError
    // ...
}
```

`on_copy_data`:
1. Get `conn_id` from `client.metadata()["_rs_conn_id"]`.
2. Look up `CopyState`; if missing, return error.
3. Append `copy_data.data()` bytes to `state.partial_line`.
4. Split on `\n`; for each complete line (skip `\.` sentinel):
   - Split on `\t` → fields.
   - If `state.columns` is non-empty and `fields.len() != state.columns.len()` → RS-2501 error.
   - Build `DmlOp::Insert { table, cols, values_tsv, row_key }`.
   - Push to `state.buf_rows`; update `state.buf_bytes`; increment `COPY_IN_BUFFER_ROWS`.
5. Leave the incomplete tail in `state.partial_line`.

`on_copy_done`:
1. Get conn_id from metadata; look up `CopyState`.
2. Flush any remaining `buf_rows` to shard.
3. Send `CommandComplete` tag: `COPY {total_rows}`.
4. Remove `CopyState` from `copy_states`.

`on_copy_fail`:
1. Clean up `CopyState`; decrement `COPY_IN_BUFFER_ROWS` by buffered count.
2. Return `PgWireError` with the fail message.

**Test gate:** `copy_in_basic_rows_visible_lfs` — starts a gateway with LFS shard;
sends 3 rows via raw pgwire COPY IN; asserts:
- `CopyInResponse` received
- `CopyDone` sent
- `CommandComplete` tag == `"COPY 3"`
- Shard contains 3 keys under `view_output/t/…`

### S5 — Auto-flush on bound exceeded (P2: memory exhaustion prevention)

**Files:**
- `crates/rockstream-gateway/src/server.rs` — `on_copy_data`

**What:** After each row is appended to `buf_rows`, check bounds:
```rust
if state.buf_rows.len() >= MAX_COPY_IN_BATCH_ROWS
   || state.buf_bytes   >= COPY_IN_FLUSH_BYTES
{
    flush_copy_batch(conn_id, &mut state, &self.shard_db).await?;
}
```
`flush_copy_batch`:
- Calls the same commit path as `handle_commit` (builds `WriteBatch`, allocates epoch, writes to shard).
- After flush: `COPY_IN_BUFFER_ROWS.fetch_sub(flushed_count, Relaxed)`.
- `state.total_rows_flushed += flushed_count`.
- `state.buf_rows.clear(); state.buf_bytes = 0;`

**Test gate (P2):** `copy_in_large_batch_no_memory_exhaustion_lfs`:
- LFS shard.
- Send 50,000 rows via COPY FROM STDIN (each row: `"id_{i}\t{i}\n"`).
- Assert `COPY_IN_BUFFER_ROWS` never exceeds `MAX_COPY_IN_BATCH_ROWS` (read the
  metric after every auto-flush threshold).
- Assert `CommandComplete` tag is `"COPY 50000"`.
- Spot-check 5 sampled rows in shard.
