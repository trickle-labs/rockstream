# v0.59.20 Plan — Common SQL & Type Completeness

## Scope and Boundary

Roadmap row (`NEW_ROADMAP.md:1844`): *"Implement and prove exactly the operation/type cells admitted by the v0.59.19 matrix: integers, Boolean, text, UUID, date, timestamp, timestamptz, bounded decimal/numeric, and common array parameter forms across expressions, filters, joins, grouping, windows, DML, prepared statements, and incremental maintenance. Cover numeric/decimal arithmetic, overflow and casts, NULL-preserving expressions and three-valued logic, text-key aggregates and joins, temporal keys, array parameters and `ANY($1)`, and deterministic collation/order behavior. Floating-point equality joins remain unsupported unless separately admitted with a new proof obligation."* Proof: *"The checked-in matrix has a passing test for every `required` cell and a tested rejection for every `unsupported` cell; numeric behavior matches the v0.59.19 contract; arrays round-trip through simple and extended protocols; text and temporal keys produce oracle-identical results; unsupported cells return their documented error and never silently fall through to an unverified implementation."* Backends: `Unit, LFS, TC`. Dependencies: `v0.59.19` (proof deps: `v0.59.17, v0.59.19`) (`NEW_ROADMAP.md:75`).

v0.59.20 delivers full type completeness and executable proof for every admitted cell in `contracts/sql-type-matrix.toml` established in v0.59.19:

1. **Admitted Type & Operation Completeness (`contracts/sql-type-matrix.toml`)**:
   - Complete execution and proof for all 14 data types across all 8 operation domains (`aggregates`, `arithmetic`, `bitwise`, `comparison`, `dml`, `joins`, `parameter_binding`, `windows`):
     - Exact Integers: `INT2` (`SMALLINT`), `INT4` (`INTEGER`), `INT8` (`BIGINT`).
     - Floating Point: `FLOAT4` (`REAL`), `FLOAT8` (`DOUBLE PRECISION`).
     - Arbitrary-Precision Fixed Point: `DECIMAL(p,s)` / `NUMERIC(p,s)` ($1 \le p \le 38, 0 \le s \le p$).
     - Boolean: `BOOLEAN` (`BOOL`).
     - Character Strings: `TEXT`, `VARCHAR(n)`.
     - Binary Octets: `BYTEA`.
     - Temporal Types: `DATE`, `TIMESTAMP` (without time zone), `TIMESTAMPTZ` (with time zone), `INTERVAL`.
     - Unique Identifier: `UUID` (128-bit canonical binary/text representation).
     - Homogeneous Sequences: `ARRAY` (1-dimensional typed arrays).

2. **Exact Arithmetic, Casts & Overflow Safety**:
   - Implement checked arithmetic (`+`, `-`, `*`, `/`, `%`, unary `-`) across integer, decimal, float, and temporal domains.
   - Enforce fail-closed numeric overflow detection with `RS-1016` (SQLSTATE `22003`) on integer and decimal operations.
   - Implement complete cast conversion matrix supporting widening, narrowing, text parsing, and formatting with explicit error rejections (`RS-1012` for invalid syntax, `RS-1015` / `RS-1016` for range/precision overflow).
   - Ensure division by zero fails closed with documented error codes without process aborts or NaN propagation in integer/decimal pipelines.

3. **ANSI Three-Valued Logic & Null Preservation**:
   - Implement strict ANSI three-valued logic (3VL: `TRUE`, `FALSE`, `UNKNOWN`) truth tables across boolean logical operators (`AND`, `OR`, `NOT`).
   - Guarantee `NULL` preservation across all scalar functions, binary arithmetic, and expression evaluation.
   - Provide complete support for `IS NULL`, `IS NOT NULL`, `COALESCE`, `NULLIF`, `IS DISTINCT FROM`, and `IS NOT DISTINCT FROM`.
   - Enforce deterministic `NULLS FIRST` / `NULLS LAST` sorting in IVM arrangement keys and window frames under the `rockstream_binary_v1` collation.

4. **Text, Temporal & UUID Key Arrangements under `rockstream_binary_v1`**:
   - Enforce `rockstream_binary_v1` collation (byte-wise UTF-8 lexicographical ordering) for all `TEXT` and `VARCHAR` keys in SlateDB index encoding.
   - Standardize microsecond-resolution ISO 8601 normalization for `DATE`, `TIMESTAMP`, and `TIMESTAMPTZ` arrangement keys.
   - Implement fixed 16-byte binary encoding for `UUID` arrangement keys ensuring bitwise total order.
   - Prove incremental view maintenance (`incremental == batch`), state growth bounds, and shard durability across LFS and MinIO for text and temporal keys.

5. **Prepared 1D Array Parameters & `ANY($1)` Protocol**:
   - Implement 1-dimensional array parameter parsing, binding, and round-tripping across simple and extended query protocols (`INT2[]`, `INT4[]`, `INT8[]`, `TEXT[]`, `UUID[]`, `FLOAT8[]`).
   - Implement scalar-to-array membership evaluation `col = ANY($1)` and `col IN (SELECT UNNEST($1))`.
   - Reject multi-dimensional arrays with `RS-1012`.

6. **Fail-Closed Rejection of Unsupported Cells**:
   - Rejection of floating-point equi-joins with `RS-1019` (SQLSTATE `0A000`).
   - Rejection of interval equi-joins with `RS-1021` (SQLSTATE `22000`).
   - Rejection of unsupported bitwise operations on non-integer types with `RS-1012` (SQLSTATE `42601`).
   - Rejection of locale-sensitive collations with `RS-1013` (SQLSTATE `0A000`).

### Non-Negotiable Ground Rules

- Prefix every shell command with `rtk` (e.g. `rtk cargo test`, `rtk git status`).

## 4. Vertical Slices

1. **Admitted Type System & Arrangement Key Encoders (`crates/rockstream-types`, `crates/rockstream-sql`)**:
   - Extend `CanonicalType` in `rockstream-types` to fully represent all 14 admitted types (`Int2`, `Int4`, `Int8`, `Float4`, `Float8`, `Decimal(u8, u8)`, `Boolean`, `Utf8`, `Binary`, `Date`, `Timestamp`, `TimestampTz`, `Interval`, `Uuid`, `Array(Box<CanonicalType>)`).
   - Implement deterministic binary key encoders and decoders in `rockstream-types` and `rockstream-sql` for all admitted types, guaranteeing total bitwise order matching `rockstream_binary_v1` collation for strings and chronological order for temporal types.

2. **Checked Arithmetic & Numeric Overflow Engine (`crates/rockstream-ops`, `crates/rockstream-sql`)**:
   - Implement checked arithmetic evaluators for all admitted numeric and temporal combinations.
   - Enforce fail-closed numeric overflow detection with `RS-1016` on integer operations (`i16`, `i32`, `i64`) and fixed-point `DECIMAL(p,s)` arithmetic up to 38 digits precision.
   - Implement safe division and modulo handling, preventing runtime panics and mapping division by zero to fail-closed error responses.

3. **ANSI 3VL & Null-Preserving Expression Engine (`crates/rockstream-ops`, `crates/rockstream-sql`)**:
   - Implement full ANSI three-valued logic truth tables for `AND`, `OR`, `NOT`, ensuring `NULL` / `UNKNOWN` propagates correctly in logical predicates.
   - Wire null preservation across all scalar expressions, string functions, and temporal arithmetic.
   - Implement `IS NULL`, `IS NOT NULL`, `COALESCE`, `NULLIF`, `IS DISTINCT FROM`, and `IS NOT DISTINCT FROM`.
   - Implement `NULLS FIRST` and `NULLS LAST` sorting in IVM arrangements and window frames.

4. **Text, Temporal & UUID Operators, Joins & Windows (`crates/rockstream-ops`, `crates/rockstream-gateway`)**:
   - Wire text key equi-joins, aggregates (`MIN`, `MAX`, `STRING_AGG`), and window functions under `rockstream_binary_v1` collation.
   - Wire temporal key equi-joins, grouping, tumbling and sliding time windows, and interval arithmetic over `DATE`, `TIMESTAMP`, and `TIMESTAMPTZ`.
   - Wire `UUID` key equi-joins, grouping, and ranking window functions with 128-bit binary ordering.

5. **Extended Wire Protocol Typed Parameter Binding & `ANY($1)` (`crates/rockstream-gateway`)**:
   - Implement binary and text format parameter binding in `PgWire` session handlers for all admitted scalar types and 1D arrays.
   - Implement `ANY($1)` scalar-in-array membership evaluation in query execution and filter pushdown paths.
   - Validate array dimensionality, rejecting multi-dimensional array parameters with `RS-1012`.

6. **Fail-Closed Rejections for Unsupported Cells (`crates/rockstream-sql`, `crates/rockstream-gateway`)**:
   - Implement explicit rejection passes for unsupported cells from Matrix G:
     - Floating-point equi-joins rejected with `RS-1019`.
     - Interval equi-joins rejected with `RS-1021`.
     - Non-integer bitwise operations rejected with `RS-1012`.
     - Non-binary collations rejected with `RS-1013`.
     - Invalid casts rejected with `RS-1012` / `RS-1015`.

7. **Differential Oracle, Durability & Conformance Verification (`crates/rockstream-oracle`, `crates/rockstream-gateway`)**:
