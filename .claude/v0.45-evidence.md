### Key Test Assertions Verified

**Session Ergonomics (Group A)**:
- `session_max_staleness_notice_emits_and_query_still_returns()`: sets `max_staleness='10s'`, forces stale frontier via `buggify!()`, asserts `RS-2018` NOTICE fires, query completes without blocking, `frontier_age_ms` in response metadata — **PASS**.

- `insert_returning_generates_uuid_default_and_persists_it()`: inserts without specifying UUID default column, `RETURNING` reflects real generated value (not null/literal-echo) matching subsequent `SELECT` — **PASS**.
