## Architecture Notes

**Causal Frontier & Source Progress Tracking:**
- Each partition in `KafkaSource` or file sequence in `S3Source` carries its own offset and watermark.
- The `poll_delta` method returns a `PollDeltaResult` containing the latest `OffsetToken` and the watermark representing progress.
- The watermark for the source is translated to the `event_time_watermark_ms` in `SourceProgress` within the operator's `FreshnessToken`.
- Under partition skew, the antichain `meet` (which takes the minimum across all sources/partitions) guarantees that the global watermark only advances when the slowest partition advances.
- Window closure in `TumbleWindowOp` depends on the global watermark advancing past the window boundary.

**Credit-based Flow Control:**
- Downstream backpressure propagates to the connector via the `credits_available` parameter in `poll_delta`.
- If `credits_available == 0`, the source connector suspends polling from Kafka / reading from S3, bounding the memory footprint at the ingestion layer.

### S4 — Clock Skew & Window Closure Test
**Files:**
- `crates/rockstream-connectors/tests/source_proof_tests.rs` (new)

**What:**
- Set up a mock `KafkaSource` with skewed partitions (e.g. partition 0 at t=500, partition 1 at t=1500).

- Assert the window for [0, 1000) does not close until partition 0 advances past t=1000.

**Test gate:** `test_kafka_clock_skew_window_closure`
