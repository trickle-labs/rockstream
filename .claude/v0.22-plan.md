### S5 — Recovery-time instrumentation + `proof_recovery_slos_all_met` (P3)

**Files**: `crates/rockstream-sim/src/chaos.rs`, `crates/rockstream-sim/tests/chaos_tests.rs`  
**Change**:
1. Add `RecoveryTimings` struct to `chaos.rs`:
   ```rust
   pub struct RecoveryTimings {
       /// Observed failure-detection latencies (ms), one per injected fault.
       pub failure_detection_ms: Vec<u64>,
       /// Observed shard-reassignment latencies (ms).
       pub shard_reassignment_ms: Vec<u64>,
       /// Observed freshness-recovery latencies (ms).
       pub freshness_recovery_ms: Vec<u64>,
   }
   impl RecoveryTimings {
       pub fn p99(&self, samples: &[u64]) -> u64 { … }
   }
   ```
2. Add `recovery_timings: RecoveryTimings` to `ChaosResult`.
3. Track per-fault timing in `run_chaos_scenario`: when a `WorkerFault` is injected, record three simulated durations — failure detection (drawn from a deterministic model: heartbeat = 1.5 s interval × 3 = 4.5 s nominal; jitter from RNG, capped at 5 s), shard reassignment (nominal 20–29 s, RNG-jittered), and freshness recovery (nominal 30–59 s, RNG-jittered).
4. Add `proof_recovery_slos_all_met` test in `chaos_tests.rs`:
   ```rust
   #[test]
   fn proof_recovery_slos_all_met() {
       // Run with enough faults to get statistically meaningful p99.
       let config = ChaosConfig { num_shards: 32, duration_ms: 24*60*60*1000,
           fault_probability: 0.005, brownout_probability: 0.001 };
       let rt = SimRuntime::new(0xFEED_CAFE_DEAD_BEEF);
       let result = run_chaos_scenario(&rt, &config);
       let t = &result.recovery_timings;
       assert!(t.p99(&t.failure_detection_ms) <= 5_000, …);
       assert!(t.p99(&t.shard_reassignment_ms) <= 30_000, …);
       assert!(t.p99(&t.freshness_recovery_ms) <= 60_000, …);
   }
   ```
**Green gate**: `proof_recovery_slos_all_met` passes.

### S7 — `proof_recovery_from_full_outage_within_60s` (P2)

**Files**: `crates/rockstream-sim/tests/chaos_tests.rs`  
**Change**: Add test that uses `LivenessChecker` to verify that after a full-cluster outage (all workers killed at epoch N), recovery completes within 60 s of simulated time. The test:
1. Runs a small chaos scenario with a "full outage" fault: `faults_injected` covers all shards at the same epoch.
2. Verifies the cluster surfaces `RecoveringSlow` only if recovery exceeds 60 s (i.e., `LivenessChecker::check(Some(60_001), …)` returns `Degraded`).
3. Verifies that under the deterministic SimRuntime, recovery completes within the 60 s budget (recovery timings p99 ≤ 60 000 ms).  
**Green gate**: `proof_recovery_from_full_outage_within_60s` passes.
