## 2. Reachability & E2E pgwire Evidence (SQL / Wire Protocol)

### 2.1 `UPDATE ... RETURNING` Execution Matrix
- **Test File**: `crates/rockstream-gateway/tests/update_returning_conformance_tests.rs`
- **Functions**:
  - `test_update_returning_star_simple`: Simple query protocol with `RETURNING *` emits full post-image row schema and updated values.
  - `test_update_returning_projected_simple`: Simple query protocol with projected columns `RETURNING val` emits projected column subset.
  - `test_update_returning_zero_matches`: Simple query protocol matching zero rows returns 0 rows with valid column description and `UPDATE 0`.
  - `test_update_returning_multi_matches`: Multi-row match emits all updated post-image tuples.
  - `test_update_returning_extended_prepared`: Extended query protocol (Parse, Bind `$1, $2`, Describe, Execute) emits projected post-image tuple.
  - `test_update_returning_explicit_transaction`: Explicit transaction `BEGIN; UPDATE ... RETURNING *; COMMIT;` emits post-image and commits state.
  - `test_update_returning_rollback_reverts_state`: `BEGIN; UPDATE ... RETURNING *; ROLLBACK;` emits post-image in TX and reverts state cleanly on rollback.

### 2.2 `DELETE ... RETURNING` Execution Matrix
- **Test File**: `crates/rockstream-gateway/tests/delete_returning_conformance_tests.rs`
- **Functions**:
  - `test_delete_returning_star_simple`: Simple query protocol with `RETURNING *` emits exact pre-image tuple of deleted record.
  - `test_delete_returning_projected_simple`: Simple query protocol with projected columns `RETURNING id` emits projected pre-image subset.
  - `test_delete_returning_zero_matches`: Zero-row match returns 0 rows with valid column descriptor and `DELETE 0`.
  - `test_delete_returning_multi_matches`: Multi-row match emits all deleted pre-image tuples.
  - `test_delete_returning_extended_prepared`: Extended query protocol with parameter `$1` executes and returns pre-image values.
  - `test_delete_returning_explicit_transaction`: Explicit transaction `BEGIN; DELETE ... RETURNING *; COMMIT;` emits pre-image and deletes record.
  - `test_delete_returning_rollback_reverts_state`: `BEGIN; DELETE ... RETURNING *; ROLLBACK;` emits pre-image in TX and restores record on rollback.

### 2.3 Idempotent DDL `IF EXISTS` & `IF NOT EXISTS` Harmonization
