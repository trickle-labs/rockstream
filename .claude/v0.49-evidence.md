## Environment notes

- Docker was available in this environment, so all MinIO/TestContainers tests
  ran for real against a live MinIO container rather than being skipped by the
  `docker_available()` guard.
- An earlier transient hang was observed while two independent `cargo test`
  invocations for `rockstream-runtime` ran concurrently against the same
  same-host shared-memory resources (a leftover process from an intermediate
  validation pass contending with a fresh full-workspace run). Once the
  leftover process was killed, each `same_host_*` test passed individually in
  under 1s and all 5 passed together in 2.19s, and the subsequent clean,
  single, full `cargo test --workspace` run completed with 0 failures. This
  was resource contention between two concurrent test processes, not a defect
  in the code under test.
