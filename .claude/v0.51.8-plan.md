## 2. Vertical Slices

### Slice 1: Physical-Plan Lowering & DiffCtx/OpNode Serving Path Fallback / Fast-Path Type Widening
- **Goal**: Allow `CREATE MATERIALIZED VIEW` over standard SQL types (e.g. `int` / `Int32`, `smallint` / `Int16`, `text` / `Utf8`, `float` / `Float64`, `numeric` / `Decimal128`, `date` / `Date32`) to compile successfully without returning `RS-1019 → RS-1013` ("AggregateOp only supports Int64 keys/values … requires the DiffCtx/OpNode physical-plan path").
- **Implementation**:
  - Update `crates/rockstream-ops/src/compile.rs` and `crates/rockstream-gateway/src/server.rs`:
    - Extend `compile_plan` and `AggregateOp` lowering to support full Arrow data type coverage (`Int8`, `Int16`, `Int32`, `Int64`, `UInt8`, `UInt16`, `UInt32`, `UInt64`, `Float32`, `Float64`, `Utf8`, `Decimal128`, `Date32`, `Timestamp`, `Boolean`) for group-by keys and aggregate value inputs.
    - Wire `DiffCtx` / `OpNode` physical plan transformation as a serving-compiler fallback whenever the fast-path compiler cannot directly lower a node.
- **Verification**: Green test in `serving_path_aggregate_matrix_tests.rs::test_basic_int_sum_group_by` executing `CREATE TABLE o (cust int, amt int); INSERT INTO o VALUES (1,10),(1,5),(2,3); CREATE MATERIALIZED VIEW mv AS SELECT cust, SUM(amt) FROM o GROUP BY cust; SELECT * FROM mv;` returning `(1,15),(2,3)` with no `RS-1019`/`RS-1013`.

### Slice 2: Aggregate Function Semantics & PostgreSQL Type Promotion
- **Goal**: Implement correct PostgreSQL-conforming type promotion for `SUM` (`int` → `bigint`/`Int64`), `AVG` (`int` → `numeric`/`Float64`), `COUNT` (`*` → `bigint`/`Int64`), and type-preserving `MIN`/`MAX` across integer, floating point, string, date, and decimal types.
- **Implementation**:
  - Update aggregate plan lowering in `crates/rockstream-ops/src/compile.rs` and `crates/rockstream-plan/` to correctly compute result schemas and state types per aggregate function.
  - Implement dynamic value extractors/accumulators for `AVG` returning oracle-matching fractional results.
- **Verification**: Green test in `serving_path_aggregate_matrix_tests.rs::test_text_key_sum_and_avg_fractional` for `text`-keyed `SELECT product, SUM(qty), AVG(qty) … GROUP BY product`.

### Slice 3: Comprehensive Serving-Path Aggregate Test Matrix
- **Goal**: Ensure comprehensive coverage across key type × value type × aggregate function combinations.
- **Implementation**:
  - Create `crates/rockstream-gateway/tests/serving_path_aggregate_matrix_tests.rs` testing combinations of keys (`int`, `smallint`, `bigint`, `text`, `float`, `numeric`, `date`) × values × aggregates (`SUM`, `AVG`, `COUNT`, `MIN`, `MAX`).
  - Cross-check every incremental view output against the DataFusion batch oracle for bit-identical equality.
- **Verification**: `serving_path_aggregate_matrix_tests.rs` passes 100%.

### Slice 4: CI Guard & Pre-existing Nexmark Suite Verification
- **Goal**: Prevent future refactors from re-introducing `Int64`-only aggregate rejection paths, while ensuring all existing Nexmark queries continue passing.
- **Implementation**:
  - Add CI guard assertion `test_ci_guard_no_int64_only_rejection` in `serving_path_aggregate_matrix_tests.rs`.
  - Verify all 12 Nexmark benchmark queries (`cargo test -p rockstream-sql --test nexmark`) pass unchanged.
- **Verification**: CI guard test and Nexmark test suite pass cleanly.
