- Pin frozen v0.72 M5 Pro profile digest and reject any altered decisions.
- Require two distinct process records: a state-larger-than-RAM eviction/compaction/migration/full-paged-recovery case, and a sustained **1800-second** multi-fault overload case with all eight named fault types observed.
- Reject missing/duplicated worker identities, implausible/sparse time-series records, invalid process/binary/oracle digest shapes, unsatisfied declared full-result hashes, missing progress/control heartbeats, OOM, over-bound worker RSS, disk, backlog, waiters, queue age and spill/compaction I/O per committed change, and recovery longer than **900 seconds**.
