# Acceptance contract: #132 Bound workload resources and qualify capacity behavior

Contract revision: v1
Source: [issue #132](https://github.com/trickle-labs/rockstream/issues/132), including its outcome and scope; `docs/implementation-plans/v0.72.md` at `6442838183ffd913b6a24860072575aacaa9c96a` (SHA-256 `66af6e6c735cb71550a40b54bec974c75db81dadd5462f5fd4a4dcf01ba9a1fb`), V072-01 through V072-13; `ROADMAP.md` sections 4, 5.2, and 18; `docs/implementation-plans/README.md`; applicable producer requirements in `docs/implementation-plans/ui-enablement.md` UIE-M5 and UIE-M7-04.
Parent contract: None
Prerequisites: Qualified v0.71 and its dependency chain, including the v0.61.1 baseline, v0.61.2 aggregate reduction, v0.62.1 worker budgets, v0.65.1 concurrency and group commit, v0.67.1 state beyond RAM, v0.68 migration, and v0.69 and v0.70 connector paths. The corresponding `sign-offs/` and linked evidence must establish these outcomes before dependent v0.72 qualification.

Intended outcome: Workloads stay within documented resource envelopes and retain fair access under pressure. Operators can reproduce capacity and cost reports and distinguish read latency, durable commit latency, and committed-result freshness. Interactive reads, subscriptions, and workload edits use bounded, truthful producer behavior.

## Unresolved gaps

- R1 has no frozen v0.72 acceptance profile. Its numerical targets and comparison timestamp must be recorded before qualification; existing v0.61.1 profiles cannot silently stand in for v0.72 decisions.
- R23 and R29 lack an agreed producer interface and qualified evidence path for UIE-M5 validation and bounded exports. The existing gateway query path does not by itself establish these promises.

## Open questions

- Which exact v0.72 values will be frozen for fairness, memory and RSS envelopes, epoch bounds, overload and recovery, offered load, latency, repetitions, noise, and per-benchmark regression thresholds? The source assigns these as preimplementation decisions.
- Which producer interface owns UIE-M5 validation and bounded result-handle export before the later console API adapts them?
- Which measured deployment and dated price source will support any cloud cost claim? Without one, the report must restrict itself to local claims.

## Out of scope

- The v0.73.1 browser-facing console API and unrestricted whole-dataset export.
- New product behavior beyond the eight canonical workloads and applicable section 5.2 cells.
- Cloud capacity or cost claims without a measured cloud deployment.
