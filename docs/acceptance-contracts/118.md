# Acceptance contract: #118 Bind prepared parameters without rewriting literals or other values

Contract revision: v1  
Source: GitHub issue #118, all five acceptance criteria; RockStream test-suite audit D1 at source revision `5d9c3b919682140ec0b365d7dba848cd5cf5ecbb`.

Intended outcome: PostgreSQL extended-query binding substitutes only actual parameter positions and preserves lexical context, types, and errors.
