## Incremental acceptance groundwork

This PR implements the fail-closed *structural and arithmetic* preflight for the comparisons owned by #139, based on the immutable M5 Pro v0.72 profile. It checks the 1K/100K/10M one-key changes, 1/20 private/shared compatible views, active 1/2/4/8 workers, and concurrent reads; all 11 scenarios must have five repeated samples with comparable workload and durability. It checks separate lookup work, state writes per change, shared execution state/write/CPU ratios, worker scaling, distinct read/commit/freshness delays, stable offered load, distinct worker identities, all required digests, and measured variation. Omitted samples and profile changes reject.

The CLI cannot launch processes or independently attest that an input digest represents the release binary, that oracle inputs were independent and complete, or that process snapshots were sampled on the claimed hardware. Its successful result says **structural_preflight_only_not_capacity_qualified**; synthetic values in unit tests are only negative-test fixtures, not release evidence.
