# Acceptance contract: #111 Make SQL oracle comparisons typed and fail on supported-query errors

Contract revision: v1  
Source: GitHub issue #111, all five acceptance criteria; RockStream test-suite audit A4 at source revision `5d9c3b919682140ec0b365d7dba848cd5cf5ecbb`.  
Parent contract: None

Intended outcome: Supported incremental SQL cases fail on compilation errors and compare complete typed, nullable, duplicate-preserving results against an independent oracle.
