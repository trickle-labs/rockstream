Intended outcome: Gateway clients can validate SQL and execute authorized, bounded read-only work through scoped result handles. Producer work stops and its reservations are released on every terminal path before completion is reported. Materialized-view reads carry the token for the actual read, and result pages expose only authorized returned typed rows with honest completion metadata.
