**Status:** partial implementation proposal, not approved acceptance or v0.72 sign-off.

Parent [#132](https://github.com/trickle-labs/rockstream/issues/132) v2:R23–R26,R29 (plus resource bound R6). Authoritative parent contract: `docs/acceptance-contracts/132.md` at `7a73050dbb28fdf61584d052b9521b2e7dce9835`; immutable plan `6442838183ffd913b6a24860072575aacaa9c96a`.

## Progress in the bounded-legacy-read PR

- Limited legacy view-prefix reads do **not** invoke the eager `scan_prefix()` path. They use `ShardReader::scan_prefix_pages` with bounded pages and a capacity-1 channel.
- The scanner task is abort-owned; reaching LIMIT, error, cancellation and disconnect drop the abort guard rather than draining the entire keyspace.
- The producer rejects a prospective response over the frozen 64 MiB interactive intermediate budget before returning rows; the wire-facing COPY OUT path in merged PR #181 retains its stricter 10,000-row/8 MiB output preflight.
- Focused storage-backed tests cover exact sorted LIMIT results, missing prefixes, zero rows, and rejection without partial results after exceeding a byte budget.

## Incomplete child acceptance

- **This is not all of #135.** Compiled-view state materialization, default unbounded requests, typed SQL validation/diagnostics, query compilation/CPU/queue/concurrency and snapshot-lifetime admission, scoped actor-bound handles, complete cancellation/revocation, read tokens and bounded typed result pages remain to be integrated.

## Follow-up: bounded COPY OUT producer-read time (#196)

The read stage of `COPY <view> TO STDOUT` is bounded by the frozen v0.72
interactive `max_wall_ms = 5000` budget. The gateway wraps the cancel-safe
`ViewReader::read_view` future in an explicit deadline; timeout returns
SQLSTATE `57014`, `[RS-9001] copy_out.read_timeout` before sending any
`CopyOutResponse`, `CopyData` or `CopyDone` frame. The dropped future
must release its owned permits. Two isolated tests check ready/error behavior
and release on timeout; one PgWire integration test checks the real timeout,
preframing SQL error, and reader cleanup.

This limits the **reader phase only**. It does not enforce a complete end-to-end
5-second producer/request/network deadline, compiled intermediate state bytes,
concurrency, snapshot lifetime, remote detached-task cancellation, handle
binding, or all eight interactive budgets. Actual process evidence and #135/#132
acceptance remain open.
