# RockStream Production Failure Matrix

Contract version: `v0.58.1`

Per [ROCKSTREAM_PROJECT_FOCUS.md](ROCKSTREAM_PROJECT_FOCUS.md) §5.5 and [NEW_ROADMAP.md](NEW_ROADMAP.md) `v0.58.1`, RockStream guarantees deterministic recovery and real-process/real-backend verification across all 11 production failure modes required for an object-storage-native IVM system.

Every failure mode cell in this matrix has:
1. An in-tree programmatic definition in `crates/rockstream-sim/src/failure_matrix.rs`.
2. A deterministic `SimRuntime` scenario covered by a permanent seed corpus.
3. An asserted recovery property (zero data loss, zero duplicates, bounded recovery time against v0.22/v0.31 SLOs — never merely "did not crash").
4. A real-backend counterpart test in the `real-cluster-chaos.yml` / soak suite or an explicit, reasoned exemption.
5. A documented time budget and absolute SLO target.
6. A CI enforcement gate (`scripts/check-failure-matrix.sh`) that verifies matrix completeness, test resolution, seed references, real-backend test links or reasoned exemptions, and non-vacuous recovery assertions.
