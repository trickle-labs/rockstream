# Experimental Examples

These deployment templates and examples are experimental and planned for full support in future milestones:
- `kafka/`: Apache Kafka / Redpanda streaming integration (planned for v0.70).
- `postgres-cdc/`: PostgreSQL Change Data Capture logical replication (planned for v0.69).

For the supported golden path in v0.61, use the standard local template via:
```bash
rockstream project new <project_name>
```
